## [](#1-2-案例準備)1-2 案例準備

接下來幾堂的實戰應用章節中，會基於一個活動(Event)報名系統的情境：

-   用戶可以在前臺看到活動信息
-   管理員可以在後台管理活動資料
-   管理員可以在後台管理用戶資料
-   用戶可以在前臺進行報名
-   管理員可以在後台管理報名資料

為了讓大家可以快速開始練習重點，請直接 clone 這個專案：[https://github.com/ihower/rails-recipes](https://github.com/ihower/rails-recipes)

請依序執行：

`git clone [[email protected]](https://ihower.tw/cdn-cgi/l/email-protection):ihower/rails-recipes.git`

`cd rails-recipes`

`bin/setup`

`bundle exec rake dev:fake`

在這個專案中，已經裝好了 Devise、Bootstrap、RSpec，並且建立好了 User 和 Event models，以及前後台的 events controller。

`rails server`

接著打開瀏覽器 http://localhost:3000

登入帳號 `[[email protected]](https://ihower.tw/cdn-cgi/l/email-protection)` 登入密碼 `12345678`

請瀏覽看看前臺活動頁面：

請進入後台操作看看新增、編輯和刪除活動資料：
