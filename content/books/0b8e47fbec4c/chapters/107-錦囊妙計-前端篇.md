## [](#bootstrap)Bootstrap

[Bootstrap](https://getbootstrap.com/)是目前最流行的前端設計框架，讓開發者也可以很輕鬆的進行網頁排版，也很有多現成的_Theme_可以套用。要在_Rails_使用_Bootstrap_，請安裝_[bootstrap-sass](https://github.com/twbs/bootstrap-sass)_

如果搭配分頁套件_kaminari_的話，執行_rails generate kaminari:views bootstrap3_就會產生對應的_kaminari_樣板。

進一步可以參考[Integrating Rails and Bootstrap](http://www.gotealeaf.com/blog/integrating-rails-and-bootstrap-part-1/)這一系列文章。

## [](#font-awesome)Font Awesome

即將推出的 Bootstrap 4 將會移除 Glyphicons，所以目前大家推薦使用 [Font-Awesome](http://fortawesome.github.io/Font-Awesome/)

Rails 可以安裝 [https://github.com/bokmann/font-awesome-rails](https://github.com/bokmann/font-awesome-rails) 這個 gem

### [](#調整顯示格式)調整顯示格式

-   Ruby 內建的方法: [Datetime#strftime](http://ruby-doc.org/core-2.2.2/Time.html#method-i-strftime)
-   Rails 內建的方法: datetime.to\_s(:short) [http://railscasts.com/episodes/31-formatting-time?view=asciicast](http://railscasts.com/episodes/31-formatting-time?view=asciicast)
-   增加或變更 Rails 的時間日期 to\_s，修改 `config/application.rb` 在最下面插入：

```
Date::DATE_FORMATS[:short] = "%Y/%m/%d"
Time::DATE_FORMATS[:short] = "%Y/%m/%d %H:%M"
```

## [](#如何畫圖表)如何畫圖表

常用圖表包括 Line chart、Pie chart、Column chart、Bar chart 等等，最常見使用 [Google Charts](https://developers.google.com/chart/interactive/docs/gallery) 或 [Highcharts](http://www.highcharts.com/) 和 [D3.js](https://d3js.org/)

搭配 Rails 的話，可以安裝 [https://github.com/ankane/chartkick](https://github.com/ankane/chartkick) 這一套最簡單，但功能較少。或是筆者推薦使用 [Chart.js](http://www.chartjs.org)。

## [](#nested-form-1-to-many)Nested Form (1-to-many)

### [](#1-對-1-的表單)1 對 1 的表單

使用 Rails 內建的 fields\_for 就可以完成，參考 [https://ihower.tw/rails4/restful-practices.html](https://ihower.tw/rails4/restful-practices.html)

### [](#1-對多的表單)1 對多的表單

如果知道固定N筆，作法同上。但如果需要可以動態加減數量，則需要 JavaScript 協助動態增減欄位。

可以使用 [https://github.com/ncri/nested\_form\_fields](https://github.com/ncri/nested_form_fields) gem (注意 Strong Parameter，這個 gem 的 README 沒提到) 或 [https://github.com/nathanvda/cocoon](https://github.com/nathanvda/cocoon) 另外參考 [http://api.rubyonrails.org/classes/ActiveRecord/NestedAttributes/ClassMethods.html](http://api.rubyonrails.org/classes/ActiveRecord/NestedAttributes/ClassMethods.html) 的 reject\_if 用法

範例 Example Code: [https://github.com/ihower/rails-exercise-ac3/tree/nested\_form](https://github.com/ihower/rails-exercise-ac3/tree/nested_form)
