![](http://se2.360simg.com/d/inn/e5e38516/button.png)

## 创建并加载一个应用

在这一节中，将编写一个browser action应用，这个应用会在360浏览器的工具栏上增加一个图标。

1.在磁盘上创建一个目录，用来放应用的代码和资源

2.在这个目录中，创建一个文本文件，命名为manifest.json，其内容为：  

{  
"name": "My First Extension",  
"version": "1.0",  
"description": "The first extension that I made.",  
"browser\_action": {  
"default\_icon": "icon.png"  
},  
"permissions": \[  
"http://api.flickr.com/"  
\]  
}

3.把这个图标放到目录中：![](https://se2.360simg.com/d/inn/5a436222/icon.png)

4.加载应用（扩展）

a)点击![](https://se2.360simg.com/d/inn/c7598a07/tool.png)图标，在菜单中选择工具〉扩展程序，这会打开扩展管理的页面

b)如果“开发人员模式”旁边有个“+”号，点击这个“+”号进入开发人员模式。“+”号会变成“-”号，同时会显示更多的按钮和信息

c)点击“载入正在开发的扩展程序…”按钮，会出现一个文件选择对话框

d)在对话框中，找到扩展目录并点击“确定”

如果应用（扩展）是正确的，它的图标就会显示在地址栏右侧，应用（扩展）的信息也会显示在扩展管理页面上，如下图所示：  
![](http://se2.360simg.com/d/inn/47870d2b/ext.png)

## 向应用（扩展）中添加代码

在这一节，会给应用（扩展）增加一点功能

1.编辑manifest.json文件，增加下面的内容:  

...  
"browser\_action": {  
"default\_icon": "icon.png",  
"popup": "popup.html"  
},  
...  

在应用（扩展）目录中，创建一个名为popup.html的文本文件，增加一些代码：[CSS and JavaScript code for hello\_world](https://src.chromium.org/viewvc/chrome/trunk/src/chrome/common/extensions/docs/examples/tutorials/getstarted/popup.html?content-type=text/plain)

2.回到扩展管理页面，点击“立即更新扩展程序”按钮，这时会重新加载修改后的应用（扩展）

3.点击应用（扩展）的图标，会弹出一个气泡窗口，显示popup.html文件的内容。样子如下：  
![](https://se2.360simg.com/d/inn/ec710445/finish.png)

如果看不到这个气泡，请严格按照上面的步骤重新做一遍。注意如果尝试加载应用（扩展）目录之外的任何html文件都会失败。
