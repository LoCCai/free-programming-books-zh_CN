## [PHP 8.6.0 RC2 available for testing](https://www.php.net/archive/2026.php#2026-09-24-1)

The PHP team is pleased to announce the first release candidate of PHP 8.6.0, RC2. It is not a typo: a mistake was made while packaging RC1, so RC2 was released instead. For a full explanation, please see this [blog post](https://scherzer.dev/Blog/20260923-no-php86-rc-1). This continues the PHP 8.6 release cycle, whose rough outline is specified in the [PHP Wiki](https://wiki.php.net/todo/php86).

Source downloads of PHP 8.6.0 RC2 are available on the [download page](https://downloads.php.net/~mbeccati/).

Please carefully test this version and report any issues found in the [GitHub Issues](https://github.com/php/php-src/issues/new?template=bug_report.yml).

**Please DO NOT use this version in production, it is an early test version.**

For more information on the new features and other changes, you can read the [NEWS](https://github.com/php/php-src/blob/php-8.6.0RC2/NEWS) file, or the [UPGRADING](https://github.com/php/php-src/blob/php-8.6.0RC2/UPGRADING) file for a complete list of upgrading notes. These files can also be found in the release archive.

The next release will be RC3, planned for 8 October 2026.

The signatures for the release can be found in the [manifest](https://gist.github.com/mbeccati/cfba591777a21f54badd12bf60bcecc9) or on the [pre-release builds page](https://www.php.net/pre-release-builds.php).

Thank you for helping us make PHP better.

25 Aug 2026

## [Last Call for the State of PHP Survey](https://www.php.net/archive/2026.php#2026-08-25-1)

The [State of PHP survey](https://surveys.jetbrains.com/s3/phpnet-state-of-php-2026) is still open, but not for much longer. It asks how PHP is working for you: what you build with, what is painful, and what you think PHP should focus on next. It takes around 15 minutes.

The survey is run by [The PHP Foundation](https://thephp.foundation/) in partnership with [PhpStorm](https://www.jetbrains.com/phpstorm/) by JetBrains.

The aggregated results will be published later this year as the State of PHP 2026 report. The anonymized raw dataset will be released along with it, so anyone in the community can check the numbers or run their own analysis.

More responses mean a better picture of what matters to PHP users. If you have not filled it in yet, please do, and share it with your colleagues and user groups.
