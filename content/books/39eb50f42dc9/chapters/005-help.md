## Documentation

A good place to start is by skimming through the ever-growing list of [frequently asked questions (with answers, of course)](https://www.php.net/FAQ.php). Then have a look at the rest of the online manual and other resources in the [documentation](https://www.php.net/docs.php) section.

For day-to-day help and troubleshooting, the broader PHP community is very active in a few places:

-   **Reddit:** [r/PHP](https://www.reddit.com/r/PHP/) — look for the Weekly help threads that are pinned to the top for beginner and general questions.
    
-   **Stack Overflow:** browse or ask questions using the [php tag](https://stackoverflow.com/questions/tagged/php).
    
-   **Discord:** there are many community-ran servers for chat-based help and discussion. Here are a couple of popular ones:
    -   [phpc.chat](https://phpc.chat/)
    -   [PHP Developers](https://discord.gg/php-developers-484326318851358720)
-   **IRC:** real-time chat at [Libera.Chat](https://libera.chat/) in **#phpc**. This channel is also bridged with Discord via [phpc.chat](https://phpc.chat/).

## User Groups & Events

Connect with local and regional PHP User Groups and find upcoming meetups, conferences, and training sessions:

-   Find a user group near you on [PHP.ug](http://php.ug/).
-   Browse upcoming events on the [event calendar](https://www.php.net/cal.php).
-   Want to list an event? Submit it [here](https://www.php.net/submit-event.php).

## Archive (Legacy Resources)

### Mailing Lists

Historically, a number of mailing lists were devoted to talking about PHP and related projects. While many are no longer active, you can still find their descriptions and archives on [this page](https://www.php.net/mailing-lists.php).

### Newsgroups

There was a PHP language NNTP newsgroup at comp.lang.php, and many of our support mailing lists are also reflected onto our news server at [news://news.php.net/](news://news.php.net). The server also has a read only web interface at [https://news-web.php.net/](https://news-web.php.net/).

Please note that these are legacy resources and primarily useful for historical reference.

## PHP.net webmasters

If you have a problem or suggestion _in connection with the PHP.net website_, [please contact the webmasters](https://www.php.net/contact.php).

If you have problems setting up PHP or using some functionality, please ask your question on a support channel detailed above, the webmasters will not answer any such questions.
