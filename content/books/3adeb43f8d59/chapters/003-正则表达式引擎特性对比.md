## 正则表达式引擎/风味说明

风味是规范，引擎是实现。

| 名称 | 说明 | 应用 |
| --- | --- | --- |
| .NET | 由 [`System.Text.RegularExpressions` 相关类](https://docs.microsoft.com/en-us/dotnet/api/system.text.regularexpressions) 提供的正则引擎。 | 基于 .Net 的语言和软件。如 C#, Visual Basic.Net, F#, Powershell, Delphi for .NET 等。 |
| Java | 由 [`java.util.regex`](https://docs.oracle.com/javase/7/docs/api/java/util/regex/package-summary.html) 包提供, 在 Java 4 (JDK 1.4.x) 及更新的版本中可用。在 Java 5 (JDK 1.5.x) 和 6 (JDK 1.6.x) 中添加了一些新功能。 | 基于 JVM 的语言和软件，如 Java, Clojure 等。 |
| Perl | 内置于 Perl 的[正则表达式引擎](https://perldoc.perl.org/perlre.html)，5.6 之前的版本不支持 Unicode。 | Perl 编程语言。 |
| PCRE | 来自开源项目 [PCRE](https://www.pcre.org/)的[正则表达式引擎](https://www.pcre.org/original/doc/html/pcrepattern.html)。 本文介绍的功能在 PCRE 5.x 和 6.x 中可用。 | REALbasic(Xojo) 语言； Delphi 组件 `TPerlRegEx` 和 Delphi XE 和 C++Builder XE 的单元 `RegularExrpessions` 和 `RegularExpressionsCore`； PHP 的 `preg` 函数； R 语言(`perl = true`)； COM 对象 Microsoft VBScript Regular Expressions 5.5。 |
| JS(JavaScript) | 由 [ECMA-262 标准](https://www.ecma-international.org/publications/standards/Ecma-262-arch.htm)[第 3 版](https://www.ecma-international.org/publications/files/ECMA-ST-ARCH/ECMA-262,%203rd%20edition,%20December%201999.pdf)定义的脚本语言(ECMAScript)中的正则表达式语法。 | JavaScript 编程语言；VBScript 中的 `RegExp`；ClojureScript 编程语言。 |
| Python | 由 Python 内置[模块 `re`](https://docs.python.org/3/library/re.html) 支持。 | Python 编程语言。 |
| Ruby | 由 Ruby 内置的[正则表达式引擎](https://ruby-doc.org/core-2.6.4/Regexp.html)。 | Ruby 编程语言。 |
| Tcl ARE | 由 Henry Spencer 为 Tcl 8.2/8.4 中命令 `regexp` 开发，被称为[高级正则表达式(Advanced Regular Expressions, ARE)](https://wiki.tcl-lang.org/page/Regular+Expression)。 | Tcl 编程语言；PostgreSQL 7.4 及更新版本；wxWidgets(`wxRE_ADVANCED`)。 |
| POSIX BRE | 由 [IEEE POSIX 标准 1003](https://pubs.opengroup.org/onlinepubs/9699919799/) 定义的[基本正则表达式（Basic Regular Expressions）](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/V1_chap09.html#tag_09_03)。 | Unix 上的软件工具；R 语言(`perl = false, extended = false`)；Tcl的 基本风味（Extended Regular Expressions），wxWidgets(`wxRE_BASIC`)。 |
| POSIX ERE | 由 [IEEE POSIX 标准 1003](https://pubs.opengroup.org/onlinepubs/9699919799/) 定义的[扩展正则表达式（Extended Regular Expressions）](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/V1_chap09.html#tag_09_04)。 | Unix 上的软件工具，如 awk, grep, egrep, emacs 等（Emacs 不支持 POSIX 字符类, 排序序列和等值字符）； MySQL, Oracle 数据库（ Oracle 支持标准外的后向引用，从 `\1` 到 `\9`），PostgreSQL 7.3 及更早版本； PHP 的 `ereg` 函数，R 语言默认状态，Tcl 的扩展风味（Extended Regular Expressions），wxWidgets(`wxRE_EXTENDED`)。 |
| GNU BRE | [GNU 基本正则表达式（GNU Basic Regular Expressions）](https://www.gnu.org/software/sed/manual/html_node/BRE-syntax.html), 包含 POSIX BRE 及 GNU 扩展。 | GNU 实现的经典 UNIX 工具，如 GNU/Linux 上的 sed 等。 |
| GNU ERE | [GNU 扩展正则表达式（Extended Regular Expressions）](https://www.gnu.org/software/sed/manual/html_node/ERE-syntax.html), 包含 POSIX ERE 及 GNU 扩展。 | GNU 实现的经典 UNIX 工具，如 GNU/Linux 上的 egrep, grep 等。 |
| XML | 由 [XML Schema 标准的附录 G](https://www.w3.org/TR/xmlschema11-2/#regexs)定义。 | XML Schema。 |
| XPath | 由 XQuery 1.0 和 XPath 2.0 标准中的[函数与运算符章节](https://www.w3.org/TR/xquery-operators/#regex-syntax)定义。 | XQuery, XPath。 |
| JGsoft | 由 [Just Great Software](https://www.just-great-software.com/) 产品使用的[正则表达式引擎](https://www.regular-expressions.info/jgsoft.html)。 | PowerGREP, EditPad Pro, AceText, RegexBuddy 等。 |
