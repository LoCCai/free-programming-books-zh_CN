The `ImageFile` module provides support functions for the image open and save functions.

In addition, it provides a [`Parser`](#PIL.ImageFile.Parser "PIL.ImageFile.Parser") class which can be used to decode an image piece by piece (e.g. while receiving it over a network connection). This class implements the same consumer interface as the standard **sgmllib** and **xmllib** modules.

## Example: Parse an image[¶](#example-parse-an-image "永久链接至标题")

from PIL import ImageFile

fp \= open("hopper.pgm", "rb")

p \= ImageFile.Parser()

while 1:
    s \= fp.read(1024)
    if not s:
        break
    p.feed(s)

im \= p.close()

im.save("copy.jpg")
