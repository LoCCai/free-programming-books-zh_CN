`PIL.TiffTags.``TAGS_V2`[¶](#PIL.TiffTags.PIL.TiffTags.TAGS_V2 "永久链接至目标")

The `TAGS_V2` dictionary maps 16-bit integer tag numbers to `PIL.TagTypes.TagInfo` tuples for metadata fields defined in the TIFF spec.

3.0.0 新版功能.

`PIL.TiffTags.``TAGS`[¶](#PIL.TiffTags.PIL.TiffTags.TAGS "永久链接至目标")

The `TAGS` dictionary maps 16-bit integer TIFF tag number to descriptive string names. For instance:

\>>> from PIL.TiffTags import TAGS
\>>> TAGS\[0x010e\]
'ImageDescription'

This dictionary contains a superset of the tags in TAGS\_V2, common EXIF tags, and other well known metadata tags.

`PIL.TiffTags.``TYPES`[¶](#PIL.TiffTags.PIL.TiffTags.TYPES "永久链接至目标")

The `TYPES` dictionary maps the TIFF type short integer to a human readable type name.
