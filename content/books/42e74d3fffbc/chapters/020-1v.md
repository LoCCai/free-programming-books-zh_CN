关于路由

-   express是自带路由
-   koa这货没有，所以，需要另外集成，koa-generator使用的是目前比较流行的koa-router（我喜欢它的是Express-style）

[https://github.com/alexmingoia/koa-router](https://github.com/alexmingoia/koa-router)

好吧

routes/users.js

```
var router = require('koa-router')();

router.get('/:id', function *(next) {
  console.log(this.params);
  console.log(this.request.params);
  this.body = 'this a users response!';
});

module.exports = router;
```

执行

```
npm run 2
```

访问[http://127.0.0.1:3000/users/alfred](http://127.0.0.1:3000/users/alfred)

首先肯定一点，this.params是可以取到params的，这点和express路由用法类似

但是注意的是

```
this.request.params != this.params
```

这说明params不是request上的方法，翻查源码，确实是如此

[https://github.com/alexmingoia/koa-router/blob/5.x/lib/router.js#L317](https://github.com/alexmingoia/koa-router/blob/5.x/lib/router.js#L317)
