从PHP7开始，大家可能会发现，不少函数不再使用传统的参数处理方式，而是改用了我们称之为Fast zend parameters parsing(FAST\_ZPP)的新型方式, 比如在PHP7之前，count函数是这样的:

PHP\_FUNCTION(count)
{
    zval \*array;
    long mode = COUNT\_NORMAL;

    if (zend\_parse\_parameters(ZEND\_NUM\_ARGS() TSRMLS\_CC, "z|l", &array, &mode) == FAILURE) {
        return;
    }
    ....
}
