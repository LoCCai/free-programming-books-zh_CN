自 2015年7月 起，此特性已在主流浏览器中得到支持，可在大多数设备和浏览器版本中正常使用。

[HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML) **`<ul>`** 元素表示无序的项目列表，通常渲染为项目符号列表。

## [尝试一下](#尝试一下)

```
<ul>
  <li>Milk</li>
  <li>
    Cheese
    <ul>
      <li>Blue cheese</li>
      <li>Feta</li>
    </ul>
  </li>
</ul>
```

```
li {
  list-style-type: circle;
}

li li {
  list-style-type: square;
}
```

## [属性](#属性)

此元素包含[全局属性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Global_attributes)。

[`compact`](#compact)

此布尔属性提示列表是否需要被渲染为更紧凑的样式。[用户代理](https://developer.mozilla.org/zh-CN/docs/Glossary/User_agent)决定如何解释这个属性，且并非所有浏览器都支持它。

**警告：**请不要使用这个属性，它已经被弃用了：请使用 [CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS) 来更改样式。如果想达到与 `compact` 属性相同的效果，将 CSS 属性 [`line-height`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/line-height) 的值设为 `80%` 即可。

[`type`](#type)

用于设置列表的着重号样式，定义于 HTML3.2 和过渡版本 HTML 4.0/4.01 中的可用值有：

-   `circle`
-   `disc`
-   `square`

存在第四种定义于 WebTV 接口的着重号样式，但并不是所有浏览器都支持：`triangle`。

如果未设置此 HTML 属性且没有 [CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS) [`list-style-type`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/list-style-type) 属性作用于这个元素，用户代理会决定使用哪种着重号样式，一般来说这也和嵌套的层级数有关。

## [使用说明](#使用说明)

-   `<ul>` 元素用来将没有数字顺序的一组数据进行分组，并且它们的数字顺序是没有意义的。举个例子，无序列表的列表项通常通过一个字符进行装饰，这些字符的形式可以是点，圆乃至方形。虽然这个字符没有直接在页面上定义，但是可以用与之相关的 CSS 对其进行操作，例如使用 [`list-style-type`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/list-style-type) 属性。
-   `<ul>` 和 [`<ol>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ol) 元素可以嵌套任意深度。此外，嵌套列表可以不受限制地在 `<ol>` 和 `<ul>` 之间交替使用。
-   [`<ol>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ol) 和 `<ul>` 元素二者都代表一组数据，不过它们彼此是有区别的，[`<ol>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ol) 元素中的顺序是有意义的。如果想确定到底需要使用哪一个列表元素，可以试着去改变数据的顺序。如果想表达的语义改变了，就需要使用 [`<ol>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ol) 元素，否则该使用 `<ul>` 元素。

### [嵌套列表](#嵌套列表)

html

```
<ul>
  <li>第一项</li>
  <li>
    第二项
    <!-- 注意，关闭的 </li> 标签没有放置在这里！-->
    <ul>
      <li>第二项第一子项</li>
      <li>
        第二项第二子项
        <!-- 第二个嵌套的无序列表也一样！-->
        <ul>
          <li>第二项第二子项第一子子项</li>
          <li>第二项第二子项第二子子项</li>
          <li>第二项第二子项第三子子项</li>
        </ul>
      </li>
      <!-- 为包含第三个无序列表的 li 关闭 </li> 标签 -->
      <li>第二项第三子项</li>
    </ul>
    <!-- 关闭的 </li> 标签在这里！ -->
  </li>
  <li>第三项</li>
</ul>
```

#### 结果

    -   [`line-height`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/line-height) 属性，用于模拟过时的 [`compact`](#compact) 属性。
    -   [`margin`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin) 属性，用于控制列表的缩进。
