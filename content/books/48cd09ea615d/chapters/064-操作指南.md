## 操作指南

本页面列出了 HTML 的操作指南，涵盖了添加 JavaScript 到页面、优化加载性能、语义化定义术语、使用 `data-*` 属性等任务，以及更多内容。

[使用 HTML 定义术语](https://developer.mozilla.org/zh-CN/docs/Web/HTML/How_to/Define_terms_with_HTML)

HTML 提供了多种方式来传达描述性语义，既可以使用内联也可以使用结构化词汇表形式。本文将探讨如何正确使用标记定义关键词。

[使用数据属性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/How_to/Use_data_attributes)

HTML 在设计时考虑到了数据的可扩展性，这些数据应与特定元素相关联，但无需具有任何定义的含义。[`data-*` 属性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Global_attributes/data-*)允许我们在标准、语义化的 HTML 元素中存储额外的信息，而不需要使用类似于非标准属性或者 DOM 额外属性之类的技巧。

[允许图片和 canvas 跨源使用](https://developer.mozilla.org/zh-CN/docs/Web/HTML/How_to/CORS_enabled_image)

HTML 规范为图片提供了 [`crossorigin`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/img#crossorigin) 属性，结合合适的 CORS 响应标头，就可以实现在 `canvas` 中使用外部域加载的 `img` 元素，就像在当前源加载一样。

[向网页添加 JavaScript](https://developer.mozilla.org/zh-CN/docs/Web/HTML/How_to/Add_JavaScript_to_your_web_page)

利用 JavaScript，让你的网页更上一层楼。在这篇文章中将了解如何在 HTML 文档中直接调用 JavaScript。

[在图像上层添加点击映射](https://developer.mozilla.org/zh-CN/docs/Web/HTML/How_to/Add_a_hit_map_on_top_of_an_image)
