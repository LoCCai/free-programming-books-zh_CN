[HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML) **`<br>`** 元素在文本中生成一个换行（回车）符号。此元素在写诗和地址时很有用，这些地方的换行都非常重要。

## [尝试一下](#尝试一下)

```
<p>
  O’er all the hilltops<br />
  Is quiet now,<br />
  In all the treetops<br />
  Hearest thou<br />
  Hardly a breath;<br />
  The birds are asleep in the trees:<br />
  Wait, soon like these<br />
  Thou too shalt rest.
</p>
```

```
p {
  font-size: 1rem;
  font-family: sans-serif;
  margin: 20px;
}
```

从上面的示例中可以看出，在我们期望文本中断的地方都包含了一个 `<br>` 元素。`<br>` 之后的文本从文本块的下一行开始

**备注：**不要用 `<br>` 来增加文本之间的行间隔；请使用 [`<p>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/p) 元素来包装文本，并使用 [CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS) [`margin`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin) 属性来控制间隔大小。

## [使用 CSS 设置样式](#使用_css_设置样式)

`<br>` 元素包含唯一且明确的语义——在文本块中创建换行符。因此，它没有自己的尺寸或视觉输出，几乎无法设计它的样式。

你可以给 `<br>` 元素设置 [`margin`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin) 从而增加文本行之间的间距，但这是一种糟糕的做法——你应该使用为此目的而设计的 [`line-height`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/line-height)。

## [无障碍考虑](#无障碍考虑)

使用 `<br>` 创建单独的文本段落不仅是糟糕的做法，而且对于借助屏幕阅读技术进行浏览的人来说也是有问题的。屏幕阅读器可能会提示该元素的存在，但不包括 `<br>` 中的任何内容。这可能会让使用屏幕阅读器的人感到困惑和沮丧。

请使用 `<p>` 元素，并使用 CSS 属性 [`margin`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin) 控制它们的间距。
