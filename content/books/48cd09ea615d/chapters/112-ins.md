## [简介](#简介)

**HTML `<ins>` 元素**定义已经被插入文档中的文本。

## [尝试一下](#尝试一下)

```
<p>&ldquo;You're late!&rdquo;</p>
<del>
  <p>&ldquo;I apologize for the delay.&rdquo;</p>
</del>
<ins cite="../howtobeawizard.html" datetime="2018-05">
  <p>&ldquo;A wizard is never late &hellip;&rdquo;</p>
</ins>
```

## [属性](#属性)

该元素支持所有 [全局特性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Global_attributes)，除此以外还支持下列属性：

[`cite`](#cite)

cite 属性的值指向一个文档的 URL，该文档解释了文本被插入或修改的原因。（目前该属性还没有被主流浏览器支持）

[`datetime`](#datetime)

该特性指示的此修改发生的时间和日期，并且该特性的值必须是[一个有效的日期或者时间字符串](https://www.w3.org/TR/2011/WD-html5-20110525/common-microsyntaxes.html#valid-date-string-with-optional-time "外部链接（在新标签页中打开）")。如果该值不能被解析为日期或者时间，则该元素不具有相关联的时间标记。

## [示例](#示例)

html

```
<ins>这一段文本是新插入至文档的。</ins>
```

### [结果](#结果)

这一段文本是新插入至文档的。
