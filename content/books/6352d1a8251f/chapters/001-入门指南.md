## 快速入门

如果你先前将 gulp 安装到全局环境中了，请执行 `npm rm --global gulp` 将 gulp 删除再继续以下操作。更多信息请参考 [Sip](https://medium.com/gulpjs/gulp-sips-command-line-interface-e53411d4467)。

## 检查 node、npm 和 npx 是否正确安装[​](#检查-nodenpm-和-npx-是否正确安装 "Direct link to 检查 node、npm 和 npx 是否正确安装")

```
node --version
```

![Output: v8.11.1](https://gulpjs.com/img/docs-node-version-command.png)

```
npm --version
```

![Output: 5.6.0](https://gulpjs.com/img/docs-npm-version-command.png)

```
npx --version
```

![Output: 9.7.1](https://gulpjs.com/img/docs-npx-version-command.png)

如果上述工具还没安装，请参考 [这里](https://nodejs.org/en/)。

```
npm install --global gulp-cli
```

## 创建项目目录并进入[​](#创建项目目录并进入 "Direct link to 创建项目目录并进入")

```
npx mkdirp my-project
```

```
cd my-project
```

## 在项目目录下创建 package.json 文件[​](#在项目目录下创建-packagejson-文件 "Direct link to 在项目目录下创建 package.json 文件")

```
npm init
```

上述命令将指引你设置项目名、版本、描述信息等。

## 安装 gulp，作为开发时依赖项[​](#安装-gulp作为开发时依赖项 "Direct link to 安装 gulp，作为开发时依赖项")

```
npm install --save-dev gulp
```

## 检查 gulp 版本[​](#检查-gulp-版本 "Direct link to 检查 gulp 版本")

```
gulp --version
```

确保输出与下面的屏幕截图匹配，否则你可能需要执行本指南中的上述步骤。

![Output: CLI version 2.0.1 & Local version 4.0.0](https://gulpjs.com/img/docs-gulp-version-command.png)

## 创建 gulpfile 文件[​](#创建-gulpfile-文件 "Direct link to 创建 gulpfile 文件")

利用任何文本编辑器在项目大的根目录下创建一个名为 gulpfile.js 的文件，并在文件中输入以下内容：

```
function defaultTask(cb) {  // place code for your default task here  cb();}exports.default = defaultTask
```

## 测试[​](#测试 "Direct link to 测试")

在项目根目录下执行 gulp 命令：

```
gulp
```

如需运行多个任务（task），可以执行 `gulp <task> <othertask>`。

## 输出结果[​](#输出结果 "Direct link to 输出结果")

默认任务（task）将执行，因为任务为空，因此没有实际动作。 ![Output: Starting default & Finished default](https://gulpjs.com/img/docs-gulp-command.png)
