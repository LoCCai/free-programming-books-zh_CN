想一想，这里的参数指针是`const char **`，有`const`限定符，却不是传入参数而是传出参数，为什么？如果是传入参数应该怎么表示？

/\* redirect\_ptr.c \*/
#include "redirect\_ptr.h"

static const char \*msg\[\] = {"Sunday", "Monday", "Tuesday", "Wednesday",
			"Thursday", "Friday", "Saturday"};
void get\_a\_day(const char \*\*pp)
{
     static int i = 0;
     \*pp = msg\[i%7\];
     i++;
}

/\* main.c \*/
#include <stdio.h>
#include "redirect\_ptr.h"

int main(void)
{
     const char \*firstday = NULL;
     const char \*secondday = NULL;
     get\_a\_day(&firstday);
     get\_a\_day(&secondday);
     printf("%s\\t%s\\n", firstday, secondday);
     return 0;
}
