如果你是初学 [Python](http://python.org/),你也许会想从了解这门语言开始。Django 是 100% 基于 Python 的， 因此，如果你对 Python 有坚实的基础，那么你必定将会使用 Django 得心应手。

如果你是编程新手，那么你最好先看看 [编程新手 Python 资源列表](http://wiki.python.org/moin/BeginnersGuide/NonProgrammers)

如果你有其他语言的编程经验并想快速学习 Python ，那么我们推荐 [Dive Into Python](http://diveintopython.net/) (有 [纸质书](http://www.amazon.com/exec/obidos/ASIN/1590593561/ref=nosim/jacobian20) 和 [中文版](http://woodpecker.org.cn/diveintopython/)). 如果这本书不符合你的要求，这里还有许多其他 [关于 Python 的书](http://wiki.python.org/moin/PythonBooks).
