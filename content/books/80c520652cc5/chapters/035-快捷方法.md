## Django shortcut functions[¶](#module-django.shortcuts "Permalink to this headline")

The package django.shortcuts collects helper functions and classes that “span” multiple levels of MVC. In other words, these functions/classes introduce controlled coupling for convenience’s sake.

## render[¶](#render "Permalink to this headline")

render(_request, template\_name\[, dictionary\]\[, context\_instance\]\[, content\_type\]\[, status\]\[, current\_app\]_)[¶](#django.shortcuts.render "Permalink to this definition")

Combines a given template with a given context dictionary and returns an [HttpResponse](https://django-chinese-docs.readthedocs.io/en/latest/ref/request-response.html#django.http.HttpResponse "django.http.HttpResponse") object with that rendered text.

[render()](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#render "render") is the same as a call to [render\_to\_response()](#django.shortcuts.render_to_response "django.shortcuts.render_to_response") with a context\_instance argument that forces the use of a [RequestContext](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#django.template.RequestContext "django.template.RequestContext").

### Required arguments[¶](#required-arguments "Permalink to this headline")

request

The request object used to generate this response.

template\_name

The full name of a template to use or sequence of template names.

### Optional arguments[¶](#optional-arguments "Permalink to this headline")

dictionary

A dictionary of values to add to the template context. By default, this is an empty dictionary. If a value in the dictionary is callable, the view will call it just before rendering the template.

context\_instance

The context instance to render the template with. By default, the template will be rendered with a RequestContext instance (filled with values from request and dictionary).

content\_type

The MIME type to use for the resulting document. Defaults to the value of the [DEFAULT\_CONTENT\_TYPE](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-DEFAULT_CONTENT_TYPE) setting.

Changed in Django 1.5: This parameter used to be called

mimetype

.

status

The status code for the response. Defaults to 200.

current\_app

A hint indicating which application contains the current view. See the [_namespaced URL resolution strategy_](https://django-chinese-docs.readthedocs.io/en/latest/topics/http/urls.html#topics-http-reversing-url-namespaces) for more information.

### Example[¶](#example "Permalink to this headline")

The following example renders the template myapp/index.html with the MIME type _application/xhtml+xml_:

from django.shortcuts import render

def my\_view(request):
    \# View code here...
    return render(request, 'myapp/index.html', {"foo": "bar"},
        content\_type\="application/xhtml+xml")

This example is equivalent to:

from django.http import HttpResponse
from django.template import RequestContext, loader

def my\_view(request):
    \# View code here...
    t \= loader.get\_template('myapp/template.html')
    c \= RequestContext(request, {'foo': 'bar'})
    return HttpResponse(t.render(c),
        content\_type\="application/xhtml+xml")

## render\_to\_response[¶](#render-to-response "Permalink to this headline")

render\_to\_response(_template\_name\[, dictionary\]\[, context\_instance\]\[, content\_type\]_)[¶](#django.shortcuts.render_to_response "Permalink to this definition")

Renders a given template with a given context dictionary and returns an [HttpResponse](https://django-chinese-docs.readthedocs.io/en/latest/ref/request-response.html#django.http.HttpResponse "django.http.HttpResponse") object with that rendered text.

### Required arguments[¶](#id1 "Permalink to this headline")

template\_name

The full name of a template to use or sequence of template names. If a sequence is given, the first template that exists will be used. See the [_template loader documentation_](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#ref-templates-api-the-python-api) for more information on how templates are found.

### Optional arguments[¶](#id2 "Permalink to this headline")

dictionary

A dictionary of values to add to the template context. By default, this is an empty dictionary. If a value in the dictionary is callable, the view will call it just before rendering the template.

context\_instance

The context instance to render the template with. By default, the template will be rendered with a [Context](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#django.template.Context "django.template.Context") instance (filled with values from dictionary). If you need to use [_context processors_](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#subclassing-context-requestcontext), render the template with a [RequestContext](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#django.template.RequestContext "django.template.RequestContext") instance instead. Your code might look something like this:

return render\_to\_response('my\_template.html',
                          my\_data\_dictionary,
                          context\_instance\=RequestContext(request))

content\_type

The MIME type to use for the resulting document. Defaults to the value of the [DEFAULT\_CONTENT\_TYPE](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-DEFAULT_CONTENT_TYPE) setting.

Changed in Django 1.5: This parameter used to be called

mimetype

.

### Example[¶](#id3 "Permalink to this headline")

The following example renders the template myapp/index.html with the MIME type _application/xhtml+xml_:

from django.shortcuts import render\_to\_response

def my\_view(request):
    \# View code here...
    return render\_to\_response('myapp/index.html', {"foo": "bar"},
        mimetype\="application/xhtml+xml")

This example is equivalent to:

from django.http import HttpResponse
from django.template import Context, loader

def my\_view(request):
    \# View code here...
    t \= loader.get\_template('myapp/template.html')
    c \= Context({'foo': 'bar'})
    return HttpResponse(t.render(c),
        content\_type\="application/xhtml+xml")

## redirect[¶](#redirect "Permalink to this headline")

redirect(_to_\[, _permanent=False_\], _\*args_, _\*\*kwargs_)[¶](#django.shortcuts.redirect "Permalink to this definition")

Returns an [HttpResponseRedirect](https://django-chinese-docs.readthedocs.io/en/latest/ref/request-response.html#django.http.HttpResponseRedirect "django.http.HttpResponseRedirect") to the appropriate URL for the arguments passed.

The arguments could be:

-   A model: the model’s get\_absolute\_url() function will be called.
-   A view name, possibly with arguments: urlresolvers.reverse() will be used to reverse-resolve the name.
-   A URL, which will be used as-is for the redirect location.

By default issues a temporary redirect; pass permanent=True to issue a permanent redirect

### Examples[¶](#examples "Permalink to this headline")

You can use the [redirect()](#django.shortcuts.redirect "django.shortcuts.redirect") function in a number of ways.

1.  By passing some object; that object’s [get\_absolute\_url()](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/instances.html#django.db.models.Model.get_absolute_url "django.db.models.Model.get_absolute_url") method will be called to figure out the redirect URL:
    
    from django.shortcuts import redirect
    
    def my\_view(request):
        ...
        object \= MyModel.objects.get(...)
        return redirect(object)
    
2.  By passing the name of a view and optionally some positional or keyword arguments; the URL will be reverse resolved using the [reverse()](https://django-chinese-docs.readthedocs.io/en/latest/ref/urlresolvers.html#django.core.urlresolvers.reverse "django.core.urlresolvers.reverse") method:
    
    def my\_view(request):
        ...
        return redirect('some-view-name', foo\='bar')
    
3.  By passing a hardcoded URL to redirect to:
    
    def my\_view(request):
        ...
        return redirect('/some/url/')
    
    This also works with full URLs:
    
    def my\_view(request):
        ...
        return redirect('http://example.com/')
    

By default, [redirect()](#django.shortcuts.redirect "django.shortcuts.redirect") returns a temporary redirect. All of the above forms accept a permanent argument; if set to True a permanent redirect will be returned:

def my\_view(request):
    ...
    object \= MyModel.objects.get(...)
    return redirect(object, permanent\=True)

## get\_object\_or\_404[¶](#get-object-or-404 "Permalink to this headline")

get\_object\_or\_404(_klass_, _\*args_, _\*\*kwargs_)[¶](#django.shortcuts.get_object_or_404 "Permalink to this definition")

Calls [get()](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet.get "django.db.models.query.QuerySet.get") on a given model manager, but it raises [Http404](https://django-chinese-docs.readthedocs.io/en/latest/topics/http/views.html#django.http.Http404 "django.http.Http404") instead of the model’s [DoesNotExist](https://django-chinese-docs.readthedocs.io/en/latest/ref/exceptions.html#django.core.exceptions.DoesNotExist "django.core.exceptions.DoesNotExist") exception.

### Required arguments[¶](#id4 "Permalink to this headline")

klass

A [Model](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/instances.html#django.db.models.Model "django.db.models.Model"), [Manager](https://django-chinese-docs.readthedocs.io/en/latest/topics/db/managers.html#django.db.models.Manager "django.db.models.Manager") or [QuerySet](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet "django.db.models.query.QuerySet") instance from which to get the object.

\*\*kwargs

Lookup parameters, which should be in the format accepted by get() and filter().

### Example[¶](#id5 "Permalink to this headline")

The following example gets the object with the primary key of 1 from MyModel:

from django.shortcuts import get\_object\_or\_404

def my\_view(request):
    my\_object \= get\_object\_or\_404(MyModel, pk\=1)

This example is equivalent to:

from django.http import Http404

def my\_view(request):
    try:
        my\_object \= MyModel.objects.get(pk\=1)
    except MyModel.DoesNotExist:
        raise Http404

Note: As with get(), a [MultipleObjectsReturned](https://django-chinese-docs.readthedocs.io/en/latest/ref/exceptions.html#django.core.exceptions.MultipleObjectsReturned "django.core.exceptions.MultipleObjectsReturned") exception will be raised if more than one object is found.

## get\_list\_or\_404[¶](#get-list-or-404 "Permalink to this headline")

get\_list\_or\_404(_klass_, _\*args_, _\*\*kwargs_)[¶](#django.shortcuts.get_list_or_404 "Permalink to this definition")

Returns the result of [filter()](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet.filter "django.db.models.query.QuerySet.filter") on a given model manager, raising [Http404](https://django-chinese-docs.readthedocs.io/en/latest/topics/http/views.html#django.http.Http404 "django.http.Http404") if the resulting list is empty.

### Required arguments[¶](#id6 "Permalink to this headline")

klass

A [Model](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/instances.html#django.db.models.Model "django.db.models.Model"), [Manager](https://django-chinese-docs.readthedocs.io/en/latest/topics/db/managers.html#django.db.models.Manager "django.db.models.Manager") or [QuerySet](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet "django.db.models.query.QuerySet") instance from which to get the list.

\*\*kwargs

Lookup parameters, which should be in the format accepted by get() and filter().

### Example[¶](#id7 "Permalink to this headline")

The following example gets all published objects from MyModel:

from django.shortcuts import get\_list\_or\_404

def my\_view(request):
    my\_objects \= get\_list\_or\_404(MyModel, published\=True)

This example is equivalent to:

from django.http import Http404

def my\_view(request):
    my\_objects \= list(MyModel.objects.filter(published\=True))
    if not my\_objects:
        raise Http404
