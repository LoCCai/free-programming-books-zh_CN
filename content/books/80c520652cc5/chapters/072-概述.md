## Django 异常[¶](#django "Permalink to this headline")

Django 提供了一些 Django 特定的异常以及许多 Python 异常。

## Django 特定异常[¶](#module-django.core.exceptions "Permalink to this headline")

### ObjectDoesNotExist 和 DoesNotExist[¶](#objectdoesnotexist-doesnotexist "Permalink to this headline")

_exception_ DoesNotExist[¶](#django.core.exceptions.DoesNotExist "Permalink to this definition")

_exception_ ObjectDoesNotExist[¶](#django.core.exceptions.ObjectDoesNotExist "Permalink to this definition")

[DoesNotExist](#django.core.exceptions.DoesNotExist "django.core.exceptions.DoesNotExist") 当一个给定参数的查询未能发现对象时抛出该异常。

[ObjectDoesNotExist](#django.core.exceptions.ObjectDoesNotExist "django.core.exceptions.ObjectDoesNotExist") 定义在 [django.core.exceptions](#module-django.core.exceptions "django.core.exceptions: Django specific exceptions") 中。 [DoesNotExist](#django.core.exceptions.DoesNotExist "django.core.exceptions.DoesNotExist") 是基类 [ObjectDoesNotExist](#django.core.exceptions.ObjectDoesNotExist "django.core.exceptions.ObjectDoesNotExist") 异常的子类， 用于提供对每一个模型类作为一种识别对象未能发现的特定类型的一种方式。

请查看 [get()](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet.get "django.db.models.query.QuerySet.get") 获取 [ObjectDoesNotExist](#django.core.exceptions.ObjectDoesNotExist "django.core.exceptions.ObjectDoesNotExist") 和 [DoesNotExist](#django.core.exceptions.DoesNotExist "django.core.exceptions.DoesNotExist") 的更多信息。

### MultipleObjectsReturned[¶](#multipleobjectsreturned "Permalink to this headline")

_exception_ MultipleObjectsReturned[¶](#django.core.exceptions.MultipleObjectsReturned "Permalink to this definition")

[MultipleObjectsReturned](#django.core.exceptions.MultipleObjectsReturned "django.core.exceptions.MultipleObjectsReturned") 当预期仅返回一个对象的查询确返回多个是抛出的异常。 该异常的基础版本由 [django.core.exceptions](#module-django.core.exceptions "django.core.exceptions: Django specific exceptions") 提供；每个模型类都 包含一个子类版本用于识别返回多个对象的特定对象类型。

请查看 [get()](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/querysets.html#django.db.models.query.QuerySet.get "django.db.models.query.QuerySet.get") 获取更多信息。

### ImproperlyConfigured[¶](#improperlyconfigured "Permalink to this headline")

_exception_ ImproperlyConfigured[¶](#django.core.exceptions.ImproperlyConfigured "Permalink to this definition")

[ImproperlyConfigured](#django.core.exceptions.ImproperlyConfigured "django.core.exceptions.ImproperlyConfigured") 当 Django 的某种配置错误时抛出的异常 – 例如 settings.py 中的值错误或不可解析。

### FieldError[¶](#fielderror "Permalink to this headline")

_exception_ FieldError[¶](#django.core.exceptions.FieldError "Permalink to this definition")

[FieldError](#django.core.exceptions.FieldError "django.core.exceptions.FieldError") 当一个模型字段有问题是抛出的异常。 发生这种情况的原因有几个：

-   模型类中的字段名与抽象基类中的字段名相同而发生冲突
-   一个由排序造成的无限循环
-   一个关键字不能从过滤参数解析
-   A field cannot be determined from a keyword in the query parameters
-   A join is not permitted on the specified field
-   字段名无效
-   一个查询包含无效排序参数

### NoReverseMatch[¶](#noreversematch "Permalink to this headline")

_exception_ NoReverseMatch[¶](#django.core.urlresolvers.NoReverseMatch "Permalink to this definition")

The [NoReverseMatch](#django.core.urlresolvers.NoReverseMatch "django.core.urlresolvers.NoReverseMatch") exception is raised by [django.core.urlresolvers](https://django-chinese-docs.readthedocs.io/en/latest/ref/urlresolvers.html#module-django.core.urlresolvers "django.core.urlresolvers") when a matching URL in your URLconf cannot be identified based on the parameters supplied.

## Database Exceptions[¶](#database-exceptions "Permalink to this headline")

Django wraps the standard database exceptions [DatabaseError](#django.db.DatabaseError "django.db.DatabaseError") and [IntegrityError](#django.db.IntegrityError "django.db.IntegrityError") so that your Django code has a guaranteed common implementation of these classes. These database exceptions are provided in [django.db](https://django-chinese-docs.readthedocs.io/en/latest/topics/db/index.html#module-django.db "django.db").

_exception_ DatabaseError[¶](#django.db.DatabaseError "Permalink to this definition")

_exception_ IntegrityError[¶](#django.db.IntegrityError "Permalink to this definition")

The Django wrappers for database exceptions behave exactly the same as the underlying database exceptions. See [**PEP 249**](http://www.python.org/dev/peps/pep-0249), the Python Database API Specification v2.0, for further information.

_exception_ models.ProtectedError[¶](#django.db.models.ProtectedError "Permalink to this definition")

Raised to prevent deletion of referenced objects when using [django.db.models.PROTECT](https://django-chinese-docs.readthedocs.io/en/latest/ref/models/fields.html#django.db.models.PROTECT "django.db.models.PROTECT"). Subclass of [IntegrityError](#django.db.IntegrityError "django.db.IntegrityError").

## Http Exceptions[¶](#http-exceptions "Permalink to this headline")

_exception_ UnreadablePostError[¶](#django.http.UnreadablePostError "Permalink to this definition")

The [UnreadablePostError](#django.http.UnreadablePostError "django.http.UnreadablePostError") is raised when a user cancels an upload. ## Transaction Exceptions[¶](#transaction-exceptions "Permalink to this headline")

_exception_ TransactionManagementError[¶](#django.db.transaction.TransactionManagementError "Permalink to this definition")

The [TransactionManagementError](#django.db.transaction.TransactionManagementError "django.db.transaction.TransactionManagementError") is raised for any and all problems related to database transactions. It is available from [django.db.transaction](https://django-chinese-docs.readthedocs.io/en/latest/topics/db/transactions.html#module-django.db.transaction "django.db.transaction").

## Python Exceptions[¶](#python-exceptions "Permalink to this headline")

Django raises built-in Python exceptions when appropriate as well. See the Python documentation for further information on the built-in [exceptions](http://docs.python.org/2.7/library/exceptions.html#exceptions "(in Python v2.7)").
