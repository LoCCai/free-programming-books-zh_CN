## The Django admin documentation generator[¶](#module-django.contrib.admindocs "Permalink to this headline")

Django’s [admindocs](#module-django.contrib.admindocs "django.contrib.admindocs: Django's admin documentation generator.") app pulls documentation from the docstrings of models, views, template tags, and template filters for any app in [INSTALLED\_APPS](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-INSTALLED_APPS) and makes that documentation available from the [Django admin](https://django-chinese-docs.readthedocs.io/en/latest/ref/contrib/admin/index.html#module-django.contrib.admin "django.contrib.admin: Django's admin site.").

In addition to providing offline documentation for all template tags and template filters that ship with Django, you may utilize admindocs to quickly document your own code.

## Overview[¶](#overview "Permalink to this headline")

To activate the [admindocs](#module-django.contrib.admindocs "django.contrib.admindocs: Django's admin documentation generator."), you will need to do the following:

-   Add [django.contrib.admindocs](#module-django.contrib.admindocs "django.contrib.admindocs: Django's admin documentation generator.") to your [INSTALLED\_APPS](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-INSTALLED_APPS).
-   Add (r'^admin/doc/', include('django.contrib.admindocs.urls')) to your urlpatterns. Make sure it’s included _before_ the r'^admin/' entry, so that requests to /admin/doc/ don’t get handled by the latter entry.
-   Install the docutils Python module ([http://docutils.sf.net/](http://docutils.sf.net/)).
-   **Optional:** Linking to templates requires the [ADMIN\_FOR](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-ADMIN_FOR) setting to be configured.
-   **Optional:** Using the admindocs bookmarklets requires the [XViewMiddleware](https://django-chinese-docs.readthedocs.io/en/latest/ref/middleware.html#module-django.middleware.doc "django.middleware.doc: Middleware to help your app self-document.") to be installed.

Once those steps are complete, you can start browsing the documentation by going to your admin interface and clicking the “Documentation” link in the upper right of the page.

## Documentation helpers[¶](#documentation-helpers "Permalink to this headline")

The following special markup can be used in your docstrings to easily create hyperlinks to other components:

 
| Django Component | reStructuredText roles |
| --- | --- |
| Models | :model:\`appname.ModelName\` |
| Views | :view:\`appname.view\_name\` |
| Template tags | :tag:\`tagname\` |
| Template filters | :filter:\`filtername\` |
| Templates | :template:\`path/to/template.html\` |

## Model reference[¶](#model-reference "Permalink to this headline")

The **models** section of the admindocs page describes each model in the system along with all the fields and methods available on it. Relationships to other models appear as hyperlinks. Descriptions are pulled from help\_text attributes on fields or from docstrings on model methods.

A model with useful documentation might look like this:

class BlogEntry(models.Model):
    """
    Stores a single blog entry, related to :model:\`blog.Blog\` and
    :model:\`auth.User\`.

    """
    slug \= models.SlugField(help\_text\="A short label, generally used in URLs.")
    author \= models.ForeignKey(User)
    blog \= models.ForeignKey(Blog)
    ...

    def publish(self):
        """Makes the blog entry live on the site."""
        ...

## View reference[¶](#view-reference "Permalink to this headline")

Each URL in your site has a separate entry in the admindocs page, and clicking on a given URL will show you the corresponding view. Helpful things you can document in your view function docstrings include:

-   A short description of what the view does.
-   The **context**, or a list of variables available in the view’s template.
-   The name of the template or templates that are used for that view.

For example:

from myapp.models import MyModel

def my\_view(request, slug):
    """
    Display an individual :model:\`myapp.MyModel\`.

    \*\*Context\*\*

    \`\`RequestContext\`\`

    \`\`mymodel\`\`
        An instance of :model:\`myapp.MyModel\`.

    \*\*Template:\*\*

    :template:\`myapp/my\_template.html\`

    """
    return render\_to\_response('myapp/my\_template.html', {
        'mymodel': MyModel.objects.get(slug\=slug)
    }, context\_instance\=RequestContext(request))

## Template reference[¶](#template-reference "Permalink to this headline")

While admindocs does not include a place to document templates by themselves, if you use the :template:\`path/to/template.html\` syntax in a docstring the resulting page will verify the path of that template with Django’s [_template loaders_](https://django-chinese-docs.readthedocs.io/en/latest/ref/templates/api.html#template-loaders). This can be a handy way to check if the specified template exists and to show where on the filesystem that template is stored.

## Included Bookmarklets[¶](#included-bookmarklets "Permalink to this headline")

Several useful bookmarklets are available from the admindocs page:

Documentation for this page

Jumps you from any page to the documentation for the view that generates that page.

Show object ID

Shows the content-type and unique ID for pages that represent a single object.

Edit this object

Jumps to the admin page for pages that represent a single object.

Using these bookmarklets requires that you are either logged into the [Django admin](https://django-chinese-docs.readthedocs.io/en/latest/ref/contrib/admin/index.html#module-django.contrib.admin "django.contrib.admin: Django's admin site.") as a [User](https://django-chinese-docs.readthedocs.io/en/latest/ref/contrib/auth.html#django.contrib.auth.models.User "django.contrib.auth.models.User") with [is\_staff](https://django-chinese-docs.readthedocs.io/en/latest/ref/contrib/auth.html#django.contrib.auth.models.User.is_staff "django.contrib.auth.models.User.is_staff") set to True, or that the [django.middleware.doc](https://django-chinese-docs.readthedocs.io/en/latest/ref/middleware.html#module-django.middleware.doc "django.middleware.doc: Middleware to help your app self-document.") middleware and [XViewMiddleware](https://django-chinese-docs.readthedocs.io/en/latest/ref/middleware.html#module-django.middleware.doc "django.middleware.doc: Middleware to help your app self-document.") are installed and you are accessing the site from an IP address listed in [INTERNAL\_IPS](https://django-chinese-docs.readthedocs.io/en/latest/ref/settings.html#std:setting-INTERNAL_IPS).
