## [语法](#语法)

css

```
/* @keyframes duration | easing-function | delay |
iteration-count | direction | fill-mode | play-state | name */
animation: 3s ease-in 1s 2 reverse both paused slidein;

/* @keyframes duration | easing-function | delay | name */
animation: 3s linear 1s slidein;

/* two animations */
animation:
  3s linear slidein,
  3s ease-out 5s slideout;
```

`animation` 属性用来指定一组或多组动画，每组之间用逗号相隔。

每组动画规定的属性如下：

-   以下属性出现 0 次或 1 次：
    
    -   [`<single-transition-timing-function>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/easing-function)
    -   [`<single-animation-iteration-count>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation#ltsingle-animation-iteration-countgt)
    -   [`<single-animation-direction>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation#ltsingle-animation-directiongt)
    -   [`<single-animation-fill-mode>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation#ltsingle-animation-fill-modegt)
    -   [`<single-animation-play-state>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation#ltsingle-animation-play-stategt)
-   animation 的 name 值可能是：none，[`<custom-ident>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/custom-ident)， [`<string>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/string)
    
-   [`<time>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/time) 可能会出现 0、1 或 2 次
    

每个动画定义中的属性值的顺序很重要：可以被解析为 [`<time>`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/time) 的第一个值被分配给[`animation-duration`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-duration)，第二个分配给 [`animation-delay`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-delay)。

每个动画定义中的值的顺序，对于区分 [`animation-name`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-name) 值与其他关键字也很重要。解析时，对于除 [`animation-name`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-name) 之外的有效的关键字，必须被前面的简写中没有找到值的属性所接受。此外，在序列化时，[`animation-name`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-name) 与以及其他属性值做区分等情况下，必须输出其他属性的默认值。

### [Values](#values)

[`<single-animation-iteration-count>`](#single-animation-iteration-count)

动画播放的次数。该值必须是[`animation-iteration-count`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-iteration-count)可用的值之一。

[`<single-animation-direction>`](#single-animation-direction)

动画播放的方向。该值必须是[`animation-direction`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-direction)可用的值之一。

[`<single-animation-fill-mode>`](#single-animation-fill-mode)

确定动画在执行之前和之后这两个阶段应用的样式。该值必须是[`animation-fill-mode`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-fill-mode)可用的值之一。

[`<single-animation-play-state>`](#single-animation-play-state)

确定动画是否正在播放。该值必须是[`animation-play-state`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/animation-play-state)中可用的值之一。

## [潜在的问题](#潜在的问题)

眨眼和闪烁的动画对于有认知问题的人来说是有问题的，比如注意力缺陷多动障碍 (ADHD)。此外，某些动画效果可以触发前庭神经紊乱、癫痫、偏头痛和暗点敏感性。

考虑提供一种暂停或禁用动画的机制，以及使用 [Reduced Motion Media Query](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)（简约运动媒体查询），为那些表示不喜欢动画的用户创建一个良好的体验。
