**CSS 颜色**模块定义了颜色、颜色类型、颜色混合、不透明度，以及如何将这些颜色和效果应用到 HTML 内容中。

虽然此模块仅包含两个 CSS 属性，即 [`color`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/color) 和 [`opacity`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/opacity)，但有超过 20 个 CSS 和 SVG 属性、CSS 图像、At 规则以及 @media 规则依赖于这两个属性。

### [色彩运用](#色彩运用)

下面的颜色语法转换器显示了当前选定颜色在[红—绿—蓝](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/color_value/rgb)（RGB）、[十六进制](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/hex-color)（HEX）、[色相、饱和度和亮度](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/color_value/hsl)（HSL）以及[色相、白度和黑度](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/hwb)（HWB）CSS 颜色格式中的值。这里所有的 RGB、HEX、HSL 和 HWB 颜色值虽然书写方式不同，但表示的是相同的颜色值。

通过[颜色选择器](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/input/color)选择颜色，并通过[滑块](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/input/range)选择透明度以更新 RGB、HEX、HSL 和 HWB 值。当选择新的颜色或不透明度值时，背景颜色和滑块会分别通过 CSS 属性 [`background-color`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/background-color) 和 [`accent-color`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/accent-color) 进行更新。

要查看此颜色语法转换器的代码，请[在 GitHub 上查看源代码](https://github.com/mdn/css-examples/blob/main/modules/colors.html "外部链接（在新标签页中打开）")。

## [指南](#指南)

[使用 CSS 为 HTML 元素应用颜色](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Guides/Colors/Applying_color)

使用 CSS 为各种类型的内容应用颜色的指南，包括所有接受 `<color>` 值的 CSS 属性。

[CSS 颜色值](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Guides/Colors/Color_values)

色彩空间的概述以及 CSS 中可用的不同 `<color>` 函数表示法。

[明智地使用颜色](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Guides/Colors/Using_color_wisely)

色彩理论及资源，包括找到合适的颜色以创建无障碍的调色板、对比度以及彩色打印。

[使用相对颜色](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors/Using_relative_colors)

本文解释了相对 CSS 颜色语法，展示了不同的选项，并给出了一些说明性的示例。

[理解颜色和亮度](https://developer.mozilla.org/zh-CN/docs/Web/Accessibility/Guides/Colors_and_Luminance)

色彩感知以及考虑到色弱（色盲）用户、视力减退用户以及患有前庭障碍或其他神经障碍的用户如何使用色彩。

[WCAG 1.4.1：颜色对比度](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Perceivable/Color_contrast)

解释背景与前景内容之间的对比度要求，以确保可读性。
