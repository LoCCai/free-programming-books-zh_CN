**CSS 列表与计数器**模块用于控制列表项项目符号的样式和位置，并可通过字符串、计数器等特性组合来操作它们的值。

列表项的标记（无论是项目符号还是序号计数器）是其最具标识性的特性。列表项并不仅限于嵌套在 [`<ol>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ol) 或 [`<ul>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/ul) 元素中的 [`<li>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/li) 元素，实际上，任何设置了 `display: list-item` 的元素都可以被视为列表项。

该模块定义了一系列 CSS 特性，用于设置和重置列表的计数器，指定用于标记的[计数器样式](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Guides/Counter_styles)或符号，并控制这些标记的位置。它还为开发者提供了创建自定义标记的能力。
