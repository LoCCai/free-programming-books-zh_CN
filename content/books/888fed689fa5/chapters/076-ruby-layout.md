## [Reference](#reference)

### [Properties](#properties)

-   [`ruby-align`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/ruby-align)
-   [`ruby-position`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/ruby-position)

The CSS ruby layout module also introduces the `ruby-merge` and `ruby-overhang` properties. Currently, no browsers support these features.

### [Display values](#display_values)

The CSS ruby layout module adds the following values to the [`display`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display) property:

-   `ruby`
-   `ruby-base`
-   `ruby-text`
-   `ruby-base-container`
-   `ruby-text-container`
