Refactoring is a systematic process of improving code without creating new functionality that can transform a mess into clean code and simple design.

### Dirty Code

[![Dirty Code](https://refactoringguru.cn/images/refactoring/content/index/refactoring-i2.png?id=dbf9c791a67f14d41250603d0bcec6fd)](https://refactoringguru.cn/refactoring/technical-debt "Dirty Code")

Dirty code is result of inexperience multiplied by tight deadlines, mismanagement, and nasty shortcuts taken during the development process.

### Clean Code

[![Clean Code](https://refactoringguru.cn/images/refactoring/content/index/refactoring-i3.png?id=e393546f4f2d0046fdbf98b75c6c35ea)](https://refactoringguru.cn/refactoring/what-is-refactoring "Clean Code")

Clean code is code that is easy to read, understand and maintain. Clean code makes software development predictable and increases the quality of a resulting product.

### Refactoring Process

[![Refactoring Process](https://refactoringguru.cn/images/refactoring/content/index/refactoring-i4.png?id=e4ba322684937f8c166dfd8f2d6ecfb1)](https://refactoringguru.cn/refactoring/how-to "Refactoring Process")

Performing refactoring step-by-step and running tests after each change are key elements of refactoring that make it predictable and safe.

### Code Smells

[![Code Smells](https://refactoringguru.cn/images/refactoring/content/index/refactoring-i5.png?id=acb5ca2349f078fa48ea57b5ad1ee0f5)](https://refactoringguru.cn/refactoring/smells "Code Smells")

Code smells are indicators of problems that can be addressed during refactoring. Code smells are easy to spot and fix, but they may be just symptoms of a deeper problem with code.

### Refactoring Techniques

[![Refactoring Techniques](https://refactoringguru.cn/images/refactoring/content/index/refactoring-i6.png?id=7f2e9d6b728193f982cfc4d2dbd384d0)](https://refactoringguru.cn/refactoring/techniques "Refactoring Techniques")

Refactoring techniques describe actual refactoring steps. Most refactoring techniques have their pros and cons. Therefore, each refactoring should be properly motivated and applied with caution.
