## 助けを求める[¶](#getting-help "このヘッドラインへのパーマリンク")

困り事ですか？手を貸しましょう！

-   [FAQ](https://docs.djangoproject.com/ja/2.0/faq/) を探してみましょう。よくある質問への答えなら、ここで見つかります。
-   特定のトピックに関する情報を探していますか？ それなら、 genindex や modindex 、そして [ドキュメントの詳しい目次](https://docs.djangoproject.com/ja/2.0/contents/) を見てください。
-   [django-users](https://docs.djangoproject.com/ja/2.0/internals/mailing-lists/#django-users-mailing-list) メーリングリストのアーカイブを検索してみるか [質問を投稿してください](https://groups.google.com/d/forum/django-users) 。
-   過去に同じ質問があるかもしれないので、 [IRC の #django チャネル](irc://irc.freenode.net/django) で質問するか [IRC のログ](https://botbot.me/freenode/django/) を検索してみましょう。
-   Django のバグを見つけたときは、 [チケットトラッカー](https://code.djangoproject.com/) で報告してください。

## 本ドキュメントの構成[¶](#how-the-documentation-is-organized "このヘッドラインへのパーマリンク")

Django にはドキュメントがたくさんあります。あらかじめドキュメントの構成の大まかな概要を知っておけば、特定のトピックを探すときに、どこを探せばいいかすぐに分かるようになるでしょう。

-   [チュートリアル](https://docs.djangoproject.com/ja/2.0/intro/) では、一連のステップを通して、実際に手を動かしながら Web アプリケーションを作ります。もし Django や Web アプリケーションの開発が初めてなら、ここから読み始めてください。下の「 [最初のステップ](#index-first-steps) 」のセクションも読んでみてください。
-   [トピックガイド](https://docs.djangoproject.com/ja/2.0/topics/) では、重要なトピックや概念について大まかに解説し、役に立つ背景情報や説明を行っています。
-   [リファレンスガイド](https://docs.djangoproject.com/ja/2.0/ref/) は、API や他の側面から見た Django の仕組みの技術的なリファレンスです。ここでは、Django の仕組みとその使い方について説明していますが、重要な概念については基本的に理解していることを前提に書かれています。
-   [How-to ガイド](https://docs.djangoproject.com/ja/2.0/howto/) はレシピ集です。よくある問題やユースケースに対して、どんなステップを踏んで解決すればいいかを説明しています。チュートリアルより発展的な内容で、Django の仕組みについてはある程度は理解していることを前提に書いてあります。

## 地理情報フレームワーク[¶](#geographic-framework "このヘッドラインへのパーマリンク")

[GeoDjango](https://docs.djangoproject.com/ja/2.0/ref/contrib/gis/) は世界規模の地理情報 Web フレームワークを目指しています。 GeoDjango の目的は、地理情報システム (GIS) のWeb アプリケーションの開発をより簡単にし、空間データ (spatially enabled data) を活用することにあります。
