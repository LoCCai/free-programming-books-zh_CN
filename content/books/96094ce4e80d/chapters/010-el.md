## Πως είναι δομημένο το documentation[¶](#how-the-documentation-is-organized "Μόνιμος σύνδεσμος σε αυτήν την κεφαλίδα")

Το Django έχει πολύ documentation. Μια επισκόπηση της οργάνωσης του θα σας βοηθήσει να γνωρίζετε πού να ψάξετε για κάτι συγκεκριμένο:

-   Οι [οδηγοί (tutorials)](https://docs.djangoproject.com/el/2.0/intro/) μας θα σας οδηγήσουν βήμα-βήμα στη δημιουργία μιας Web εφαρμογής (Web application). Ξεκινήστε από εκεί εάν είστε καινούργιοι στο Django ή στο Web application development. Επίσης ρίξτε μια ματιά στα «[Πρώτα βήματα](#index-first-steps)» πιο κάτω.
-   Το άρθρο [χρησιμοποιώντας το Django](https://docs.djangoproject.com/el/2.0/topics/) συζητά επιγραμματικά για βασικά θέματα και έννοιες και παρέχει χρήσιμες πληροφορίες και τεκμηριώσεις.
-   Οι [οδηγοί αναφορών](https://docs.djangoproject.com/el/2.0/ref/) περιέχουν τεχνικές αναφορές για τα API και άλλες πτυχές του μηχανισμού του Django. Περιγράφουν πώς λειτουργεί και πώς να το χρησιμοποιήσετε αλλά προϋποθέτει ότι έχετε γνώση βασικών θεμάτων σχετικά με το Django.
-   Οι [οδηγοί how-to](https://docs.djangoproject.com/el/2.0/howto/) είναι συνταγές. Σας καθοδηγούν μέσα από βήματα για την επίλυση κοινών προβλημάτων. Είναι πιο προχωρημένα από τα tutorials και προϋποθέτουν ότι έχετε γνώση του τρόπου λειτουργίας του Django.

## Γεωγραφικό framework[¶](#geographic-framework "Μόνιμος σύνδεσμος σε αυτήν την κεφαλίδα")

Το [GeoDjango](https://docs.djangoproject.com/el/2.0/ref/contrib/gis/) σκοπεύει να γίνει ένα παγκόσμιο γεωγραφικό (geographic) Web framework. Ο στόχος του είναι να κάνει όσο το δυνατόν πιο εύκολη τη συγγραφή GIS Web εφαρμογών και να εκμεταλλευτεί τη δύναμη των χωρικά ενεργοποιημένων δεδομένων (spatially enabled data).
