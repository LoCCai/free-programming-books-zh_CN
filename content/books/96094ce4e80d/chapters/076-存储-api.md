## Getting the current storage class[¶](#getting-the-current-storage-class "Permalink to this headline")

Django provides two convenient ways to access the current storage class:

_class_ `DefaultStorage`[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#DefaultStorage)[¶](#django.core.files.storage.DefaultStorage "Permalink to this definition")

[`DefaultStorage`](#django.core.files.storage.DefaultStorage "django.core.files.storage.DefaultStorage") provides lazy access to the current default storage system as defined by [`DEFAULT_FILE_STORAGE`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-DEFAULT_FILE_STORAGE). [`DefaultStorage`](#django.core.files.storage.DefaultStorage "django.core.files.storage.DefaultStorage") uses [`get_storage_class()`](#django.core.files.storage.get_storage_class "django.core.files.storage.get_storage_class") internally.

`get_storage_class`(_import\_path=None_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#get_storage_class)[¶](#django.core.files.storage.get_storage_class "Permalink to this definition")

Returns a class or module which implements the storage API.

When called without the `import_path` parameter `get_storage_class` will return the current default storage system as defined by [`DEFAULT_FILE_STORAGE`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-DEFAULT_FILE_STORAGE). If `import_path` is provided, `get_storage_class` will attempt to import the class or module from the given path and will return it if successful. An exception will be raised if the import is unsuccessful.

## The `FileSystemStorage` class[¶](#the-filesystemstorage-class "Permalink to this headline")

_class_ `FileSystemStorage`(_location=None_, _base\_url=None_, _file\_permissions\_mode=None_, _directory\_permissions\_mode=None_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#FileSystemStorage)[¶](#django.core.files.storage.FileSystemStorage "Permalink to this definition")

The [`FileSystemStorage`](#django.core.files.storage.FileSystemStorage "django.core.files.storage.FileSystemStorage") class implements basic file storage on a local filesystem. It inherits from [`Storage`](#django.core.files.storage.Storage "django.core.files.storage.Storage") and provides implementations for all the public methods thereof.

`location`[¶](#django.core.files.storage.FileSystemStorage.location "Permalink to this definition")

Absolute path to the directory that will hold the files. Defaults to the value of your [`MEDIA_ROOT`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-MEDIA_ROOT) setting.

`base_url`[¶](#django.core.files.storage.FileSystemStorage.base_url "Permalink to this definition")

URL that serves the files stored at this location. Defaults to the value of your [`MEDIA_URL`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-MEDIA_URL) setting.

`file_permissions_mode`[¶](#django.core.files.storage.FileSystemStorage.file_permissions_mode "Permalink to this definition")

The file system permissions that the file will receive when it is saved. Defaults to [`FILE_UPLOAD_PERMISSIONS`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-FILE_UPLOAD_PERMISSIONS).

`directory_permissions_mode`[¶](#django.core.files.storage.FileSystemStorage.directory_permissions_mode "Permalink to this definition")

The file system permissions that the directory will receive when it is saved. Defaults to [`FILE_UPLOAD_DIRECTORY_PERMISSIONS`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-FILE_UPLOAD_DIRECTORY_PERMISSIONS).

Note

The `FileSystemStorage.delete()` method will not raise an exception if the given file name does not exist.

`get_created_time`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#FileSystemStorage.get_created_time)[¶](#django.core.files.storage.FileSystemStorage.get_created_time "Permalink to this definition")

Returns a [`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime "(in Python v3.7)") of the system's ctime, i.e. [`os.path.getctime()`](https://docs.python.org/3/library/os.path.html#os.path.getctime "(in Python v3.7)"). On some systems (like Unix), this is the time of the last metadata change, and on others (like Windows), it's the creation time of the file.

## The `Storage` class[¶](#the-storage-class "Permalink to this headline")

_class_ `Storage`[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage)[¶](#django.core.files.storage.Storage "Permalink to this definition")

The [`Storage`](#django.core.files.storage.Storage "django.core.files.storage.Storage") class provides a standardized API for storing files, along with a set of default behaviors that all other storage systems can inherit or override as necessary.

Note

When methods return naive `datetime` objects, the effective timezone used will be the current value of `os.environ['TZ']`; note that this is usually set from Django's [`TIME_ZONE`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-TIME_ZONE).

`delete`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.delete)[¶](#django.core.files.storage.Storage.delete "Permalink to this definition")

Deletes the file referenced by `name`. If deletion is not supported on the target storage system this will raise `NotImplementedError` instead

`exists`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.exists)[¶](#django.core.files.storage.Storage.exists "Permalink to this definition")

Returns `True` if a file referenced by the given name already exists in the storage system, or `False` if the name is available for a new file.

`get_accessed_time`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.get_accessed_time)[¶](#django.core.files.storage.Storage.get_accessed_time "Permalink to this definition")

Returns a [`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime "(in Python v3.7)") of the last accessed time of the file. For storage systems unable to return the last accessed time this will raise [`NotImplementedError`](https://docs.python.org/3/library/exceptions.html#NotImplementedError "(in Python v3.7)").

If [`USE_TZ`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-USE_TZ) is `True`, returns an aware `datetime`, otherwise returns a naive `datetime` in the local timezone.

`get_available_name`(_name_, _max\_length=None_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.get_available_name)[¶](#django.core.files.storage.Storage.get_available_name "Permalink to this definition")

Returns a filename based on the `name` parameter that's free and available for new content to be written to on the target storage system.

The length of the filename will not exceed `max_length`, if provided. If a free unique filename cannot be found, a [`SuspiciousFileOperation`](https://docs.djangoproject.com/zh-hans/2.0/ref/exceptions/#django.core.exceptions.SuspiciousOperation "django.core.exceptions.SuspiciousOperation") exception will be raised.

If a file with `name` already exists, an underscore plus a random 7 character alphanumeric string is appended to the filename before the extension.

`get_created_time`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.get_created_time)[¶](#django.core.files.storage.Storage.get_created_time "Permalink to this definition")

Returns a [`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime "(in Python v3.7)") of the creation time of the file. For storage systems unable to return the creation time this will raise [`NotImplementedError`](https://docs.python.org/3/library/exceptions.html#NotImplementedError "(in Python v3.7)").

If [`USE_TZ`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-USE_TZ) is `True`, returns an aware `datetime`, otherwise returns a naive `datetime` in the local timezone.

`get_modified_time`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.get_modified_time)[¶](#django.core.files.storage.Storage.get_modified_time "Permalink to this definition")

Returns a [`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime "(in Python v3.7)") of the last modified time of the file. For storage systems unable to return the last modified time this will raise [`NotImplementedError`](https://docs.python.org/3/library/exceptions.html#NotImplementedError "(in Python v3.7)").

If [`USE_TZ`](https://docs.djangoproject.com/zh-hans/2.0/ref/settings/#std:setting-USE_TZ) is `True`, returns an aware `datetime`, otherwise returns a naive `datetime` in the local timezone.

`get_valid_name`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.get_valid_name)[¶](#django.core.files.storage.Storage.get_valid_name "Permalink to this definition")

Returns a filename based on the `name` parameter that's suitable for use on the target storage system.

`generate_filename`(_filename_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.generate_filename)[¶](#django.core.files.storage.Storage.generate_filename "Permalink to this definition")

Validates the `filename` by calling [`get_valid_name()`](https://docs.djangoproject.com/zh-hans/2.0/howto/custom-file-storage/#django.core.files.storage.get_valid_name "django.core.files.storage.get_valid_name") and returns a filename to be passed to the [`save()`](#django.core.files.storage.Storage.save "django.core.files.storage.Storage.save") method.

The `filename` argument may include a path as returned by [`FileField.upload_to`](https://docs.djangoproject.com/zh-hans/2.0/ref/models/fields/#django.db.models.FileField.upload_to "django.db.models.FileField.upload_to"). In that case, the path won't be passed to [`get_valid_name()`](https://docs.djangoproject.com/zh-hans/2.0/howto/custom-file-storage/#django.core.files.storage.get_valid_name "django.core.files.storage.get_valid_name") but will be prepended back to the resulting name.

The default implementation uses [`os.path`](https://docs.python.org/3/library/os.path.html#module-os.path "(in Python v3.7)") operations. Override this method if that's not appropriate for your storage.

`listdir`(_path_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.listdir)[¶](#django.core.files.storage.Storage.listdir "Permalink to this definition")

Lists the contents of the specified path, returning a 2-tuple of lists; the first item being directories, the second item being files. For storage systems that aren't able to provide such a listing, this will raise a `NotImplementedError` instead.

`open`(_name_, _mode='rb'_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.open)[¶](#django.core.files.storage.Storage.open "Permalink to this definition")

Opens the file given by `name`. Note that although the returned file is guaranteed to be a `File` object, it might actually be some subclass. In the case of remote file storage this means that reading/writing could be quite slow, so be warned.

`path`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.path)[¶](#django.core.files.storage.Storage.path "Permalink to this definition")

The local filesystem path where the file can be opened using Python's standard `open()`. For storage systems that aren't accessible from the local filesystem, this will raise `NotImplementedError` instead.

`save`(_name_, _content_, _max\_length=None_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.save)[¶](#django.core.files.storage.Storage.save "Permalink to this definition")

Saves a new file using the storage system, preferably with the name specified. If there already exists a file with this name `name`, the storage system may modify the filename as necessary to get a unique name. The actual name of the stored file will be returned.

The `max_length` argument is passed along to [`get_available_name()`](https://docs.djangoproject.com/zh-hans/2.0/howto/custom-file-storage/#django.core.files.storage.get_available_name "django.core.files.storage.get_available_name").

The `content` argument must be an instance of [`django.core.files.File`](https://docs.djangoproject.com/zh-hans/2.0/ref/files/file/#django.core.files.File "django.core.files.File") or a file-like object that can be wrapped in `File`.

`size`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.size)[¶](#django.core.files.storage.Storage.size "Permalink to this definition")

Returns the total size, in bytes, of the file referenced by `name`. For storage systems that aren't able to return the file size this will raise `NotImplementedError` instead.

`url`(_name_)[\[source\]](https://docs.djangoproject.com/zh-hans/2.0/_modules/django/core/files/storage/#Storage.url)[¶](#django.core.files.storage.Storage.url "Permalink to this definition")

Returns the URL where the contents of the file referenced by `name` can be accessed. For storage systems that don't support access by URL this will raise `NotImplementedError` instead.
