Release notes for the official Django releases. Each release note will tell you what's new in each version, and will also describe any backwards-incompatible changes made in that version.

For those [upgrading to a new version of Django](https://docs.djangoproject.com/zh-hans/2.0/howto/upgrade-version/), you will need to check all the backwards-incompatible changes and [deprecated features](https://docs.djangoproject.com/zh-hans/2.0/internals/deprecation/) for each 'final' release from the one after your current Django version, up to and including the new version.

## Security releases[¶](#security-releases "Permalink to this headline")

Whenever a security issue is disclosed via [Django's security policies](https://docs.djangoproject.com/zh-hans/2.0/internals/security/), appropriate release notes are now added to all affected release series.

Additionally, [an archive of disclosed security issues](https://docs.djangoproject.com/zh-hans/2.0/releases/security/) is maintained.
