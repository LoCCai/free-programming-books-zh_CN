## [Rust by Example](#rust-by-example)

[Rust](https://www.rust-lang.org/) is a modern systems programming language focusing on safety, speed, and concurrency. It accomplishes these goals by being memory safe without using garbage collection.

Rust by Example (RBE) is a collection of runnable examples that illustrate various Rust concepts and standard libraries. To get even more out of these examples, don't forget to [install Rust locally](https://www.rust-lang.org/tools/install) and check out the [official docs](https://doc.rust-lang.org/std/). Additionally for the curious, you can also [check out the source code for this site](https://github.com/rust-lang/rust-by-example).

Now let's begin!

-   [Hello World](https://rustwiki.org/en/rust-by-example/hello.html) - Start with a traditional Hello World program.
    
-   [Primitives](https://rustwiki.org/en/rust-by-example/primitives.html) - Learn about signed integers, unsigned integers and other primitives.
    
-   [Custom Types](https://rustwiki.org/en/rust-by-example/custom_types.html) - `struct` and `enum`.
    
-   [Variable Bindings](https://rustwiki.org/en/rust-by-example/variable_bindings.html) - mutable bindings, scope, shadowing.
    
-   [Types](https://rustwiki.org/en/rust-by-example/types.html) - Learn about changing and defining types.
    
-   [Conversion](https://rustwiki.org/en/rust-by-example/conversion.html)
    
-   [Expressions](https://rustwiki.org/en/rust-by-example/expression.html)
    
-   [Flow of Control](https://rustwiki.org/en/rust-by-example/flow_control.html) - `if`/`else`, `for`, and others.
    
-   [Functions](https://rustwiki.org/en/rust-by-example/fn.html) - Learn about Methods, Closures and Higher Order Functions.
    
-   [Modules](https://rustwiki.org/en/rust-by-example/mod.html) - Organize code using modules
    
-   [Crates](https://rustwiki.org/en/rust-by-example/crates.html) - A crate is a compilation unit in Rust. Learn to create a library.
    
-   [Cargo](https://rustwiki.org/en/rust-by-example/cargo.html) - Go through some basic features of the official Rust package management tool.
    
-   [Attributes](https://rustwiki.org/en/rust-by-example/attribute.html) - An attribute is metadata applied to some module, crate or item.
    
-   [Generics](https://rustwiki.org/en/rust-by-example/generics.html) - Learn about writing a function or data type which can work for multiple types of arguments.
    
-   [Scoping rules](https://rustwiki.org/en/rust-by-example/scope.html) - Scopes play an important part in ownership, borrowing, and lifetimes.
    
-   [Traits](https://rustwiki.org/en/rust-by-example/trait.html) - A trait is a collection of methods defined for an unknown type: `Self`
    
-   [Macros](https://rustwiki.org/en/rust-by-example/macros.html)
    
-   [Error handling](https://rustwiki.org/en/rust-by-example/error.html) - Learn Rust way of handling failures.
    
-   [Std library types](https://rustwiki.org/en/rust-by-example/std.html) - Learn about some custom types provided by `std` library.
    
-   [Std misc](https://rustwiki.org/en/rust-by-example/std_misc.html) - More custom types for file handling, threads.
    
-   [Testing](https://rustwiki.org/en/rust-by-example/testing.html) - All sorts of testing in Rust.
    
-   [Unsafe Operations](https://rustwiki.org/en/rust-by-example/unsafe.html)
    
-   [Compatibility](https://rustwiki.org/en/rust-by-example/compatibility.html)
    
-   [Meta](https://rustwiki.org/en/rust-by-example/meta.html) - Documentation, Benchmarking.
