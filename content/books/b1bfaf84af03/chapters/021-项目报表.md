## 生成报表

本文档提供了对项目中各种报表的概述，这些报表生成自 [Maven](https://maven.apache.org) 每一个报表在以下简要介绍。

## 概述

| 文档 | 描述 |
| --- | --- |
| [Javadoc](https://mybatis.org/mybatis-3/zh_CN/apidocs/index.html) | Javadoc API documentation. |
| [Source Xref](https://mybatis.org/mybatis-3/zh_CN/xref/index.html) | HTML based, cross-reference version of Java source code. |
| [Test Source Xref](https://mybatis.org/mybatis-3/zh_CN/xref-test/index.html) | HTML based, cross-reference version of Java test source code. |
| [SpotBugs](https://mybatis.org/mybatis-3/zh_CN/spotbugs.html) | Generates a source code report with the SpotBugs Library. |
| [Surefire](https://mybatis.org/mybatis-3/zh_CN/surefire.html) | Report on the test results of the project. |
| [Checkstyle](https://mybatis.org/mybatis-3/zh_CN/checkstyle.html) | Report on coding style conventions. |
| [CPD](https://mybatis.org/mybatis-3/zh_CN/cpd.html) | Duplicate code detection. |
| [PMD](https://mybatis.org/mybatis-3/zh_CN/pmd.html) | Verification of coding rules. |
| [Tag List](https://mybatis.org/mybatis-3/zh_CN/taglist.html) | Report on various tags found in the code. |
| [Clirr](https://mybatis.org/mybatis-3/zh_CN/clirr-report.html) | Report on binary and source API differences between releases |
| [Dependency Updates Report](https://mybatis.org/mybatis-3/zh_CN/dependency-updates-report.html) | Provides details of the dependencies which have updated versions available. |
| [Parent Updates Report](https://mybatis.org/mybatis-3/zh_CN/parent-updates-report.html) | Provides information on parent artifact updates |
| [Plugin Updates Report](https://mybatis.org/mybatis-3/zh_CN/plugin-updates-report.html) | Provides details of the plugins used by this project which have newer versions available. |
| [Property Updates Report](https://mybatis.org/mybatis-3/zh_CN/property-updates-report.html) | Provides details of properties which control versions of dependencies and/or plugins, and indicates any newer versions which are available. |
| [JaCoCo](https://mybatis.org/mybatis-3/zh_CN/jacoco/index.html) | JaCoCo Coverage Report. |
