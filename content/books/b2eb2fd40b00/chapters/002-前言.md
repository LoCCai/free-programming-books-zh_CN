## 前言

本书是 PostgreSQL 的官方文档。它是由 PostgreSQL 开发人员和其它志愿者撰写的，并且与 PostgreSQL 软件的开发同步进行。它描述了当前版本的 PostgreSQL 官方支持的所有功能。

为了便于管理有关 PostgreSQL 的大量信息，本书被组织成了几个部分。不同的部分针对在 PostgreSQL 上有着不同经验、不同认识层次、不同阶段的用户：

-   [Part I](https://www.jinbuguo.com/postgresql/manual/tutorial.html) 是一个给新用户的非正式介绍。
    
-   [Part II](https://www.jinbuguo.com/postgresql/manual/sql.html) 记载了 SQL 查询语言环境，包括数据类型和函数以及用户层次的性能调优。每个 PostgreSQL 用户都应该阅读这些内容。
    
-   [Part III](https://www.jinbuguo.com/postgresql/manual/admin.html) 描述了服务器的安装和管理。每个运行 PostgreSQL 的人，不管是个人使用还是为别人维护，都应该阅读这部分内容。
    
-   [Part IV](https://www.jinbuguo.com/postgresql/manual/client-interfaces.html) 描述 PostgreSQL 客户端程序的编程接口。
    
-   [Part V](https://www.jinbuguo.com/postgresql/manual/server-programming.html) 包含了那些给高级用户查看的信息，比如服务器的扩展能力等。其中的内容包括用户定义数据类型和函数等。
    
-   [Part VI](https://www.jinbuguo.com/postgresql/manual/reference.html) 包含了有关 SQL 命令的参考信息以及客户端和服务器程序开发的信息。这部分支持其它部分，其中的信息是结构化组织并且按照命令/程序名排序的。
    
-   [Part VII](https://www.jinbuguo.com/postgresql/manual/internals.html) 包含可能用于 PostgreSQL 开发人员的分类信息。
