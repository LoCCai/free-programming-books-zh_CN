欢迎阅读 PostgreSQL 教程。下面几个章节主要是给那些对于 PostgreSQL 关系数据库概念和 SQL 语言尚不熟悉的朋友一次简单介绍。我们只是假设你有一些关于如何使用计算机的基本知识。并不要求特殊的 Unix 或者编程经验。这部分的主要目的是给你一些手把手的经验，告诉你一些有关 PostgreSQL 系统的重要方面。我们无意把这部分写成一份有关这个题目的完整材料。

在你阅读完这份教程之后你可能想继续阅读 [Part II](https://www.jinbuguo.com/postgresql/manual/sql.html) 以获取有关 SQL 语言的更多一般性信息，或者是 [Part IV](https://www.jinbuguo.com/postgresql/manual/client-interfaces.html) 获取有关为 PostgreSQL 开发应用的信息。那些安装并维护自己的服务器的人应该看看 [Part III](https://www.jinbuguo.com/postgresql/manual/admin.html) 。
