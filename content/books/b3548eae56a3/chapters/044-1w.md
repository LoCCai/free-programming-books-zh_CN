当你抓取了你要的数据(Items)，你就会想要将他们持久化或导出它们，并应用在其他的程序。这是整个抓取过程的目的。

为此，Scrapy提供了Item Exporters 来创建不同的输出格式，如XML，CSV或JSON。

## 使用 Item Exporter[¶](#item-exporter "永久链接至标题")

如果你很忙，只想使用 Item Exporter 输出数据，请查看 [Feed exports](https://scrapy-chs.readthedocs.io/zh_CN/latest/topics/feed-exports.html#topics-feed-exports). 相反，如果你想知道Item Exporter 是如何工作的，或需要更多的自定义功能（不包括默认的 exports），请继续阅读下文。

为了使用 Item Exporter，你必须对 Item Exporter 及其参数 (args) 实例化。每个 Item Exporter 需要不同的参数，详细请查看 [Item Exporters 参考资料](#topics-exporters-reference) 。在实例化了 exporter 之后，你必须：

1.  调用方法 [`start_exporting()`](#scrapy.contrib.exporter.BaseItemExporter.start_exporting "scrapy.contrib.exporter.BaseItemExporter.start_exporting") 以标识 exporting 过程的开始。
2.  对要导出的每个项目调用 [`export_item()`](#scrapy.contrib.exporter.BaseItemExporter.export_item "scrapy.contrib.exporter.BaseItemExporter.export_item") 方法。
3.  最后调用 [`finish_exporting()`](#scrapy.contrib.exporter.BaseItemExporter.finish_exporting "scrapy.contrib.exporter.BaseItemExporter.finish_exporting") 表示 exporting 过程的结束

这里，你可以看到一个 [Item Pipeline](https://scrapy-chs.readthedocs.io/zh_CN/latest/topics/item-pipeline.html) ，它使用 Item Exporter 导出 items 到不同的文件，每个 spider 一个:

from scrapy import signals
from scrapy.contrib.exporter import XmlItemExporter

class XmlExportPipeline(object):

    def \_\_init\_\_(self):
        self.files \= {}

     @classmethod
     def from\_crawler(cls, crawler):
         pipeline \= cls()
         crawler.signals.connect(pipeline.spider\_opened, signals.spider\_opened)
         crawler.signals.connect(pipeline.spider\_closed, signals.spider\_closed)
         return pipeline

    def spider\_opened(self, spider):
        file \= open('%s\_products.xml' % spider.name, 'w+b')
        self.files\[spider\] \= file
        self.exporter \= XmlItemExporter(file)
        self.exporter.start\_exporting()

    def spider\_closed(self, spider):
        self.exporter.finish\_exporting()
        file \= self.files.pop(spider)
        file.close()

    def process\_item(self, item, spider):
        self.exporter.export\_item(item)
        return item

序列化 item fields

* * *

B默认情况下，该字段值将不变的传递到序列化库，如何对其进行序列化的决定被委托给每一个特定的序列化库。

但是，你可以自定义每个字段值如何序列化在它被传递到序列化库中之前。

有两种方法可以自定义一个字段如何被序列化，请看下文。

### 1\. 在 field 类中声明一个 serializer[¶](#field-serializer "永久链接至标题")

您可以在 [field metadata](https://scrapy-chs.readthedocs.io/zh_CN/latest/topics/items.html#topics-items-fields) 声明一个 serializer。该 serializer 必须可调用，并返回它的序列化形式。

实例:

import scrapy

def serialize\_price(value):
    return '$ %s' % str(value)

class Product(scrapy.Item):
    name \= scrapy.Field()
    price \= scrapy.Field(serializer\=serialize\_price)

### 2\. 覆盖(overriding) serialize\_field() 方法[¶](#overriding-serialize-field "永久链接至标题")

你可以覆盖 [`serialize_field()`](#scrapy.contrib.exporter.BaseItemExporter.serialize_field "scrapy.contrib.exporter.BaseItemExporter.serialize_field") 方法来自定义如何输出你的数据。

在你的自定义代码后确保你调用父类的 [`serialize_field()`](#scrapy.contrib.exporter.BaseItemExporter.serialize_field "scrapy.contrib.exporter.BaseItemExporter.serialize_field") 方法。

实例:

from scrapy.contrib.exporter import XmlItemExporter

class ProductXmlExporter(XmlItemExporter):

    def serialize\_field(self, field, name, value):
        if field \== 'price':
            return '$ %s' % str(value)
        return super(Product, self).serialize\_field(field, name, value)

## Item Exporters 参考资料[¶](#topics-exporters-reference "永久链接至标题")

下面是一些Scrapy内置的 Item Exporters类. 其中一些包括了实例, 假设你要输出以下2个Items:

Item(name\='Color TV', price\='1200')

### BaseItemExporter[¶](#baseitemexporter "永久链接至标题")

_class_ `scrapy.contrib.exporter.``BaseItemExporter`(_fields\_to\_export=None_, _export\_empty\_fields=False_, _encoding='utf-8'_)[¶](#scrapy.contrib.exporter.BaseItemExporter "永久链接至目标")

这是一个对所有 Item Exporters 的(抽象)父类。它对所有(具体) Item Exporters 提供基本属性，如定义export什么fields, 是否export空fields, 或是否进行编码。

你可以在构造器中设置它们不同的属性值: [`fields_to_export`](#scrapy.contrib.exporter.BaseItemExporter.fields_to_export "scrapy.contrib.exporter.BaseItemExporter.fields_to_export") , [`export_empty_fields`](#scrapy.contrib.exporter.BaseItemExporter.export_empty_fields "scrapy.contrib.exporter.BaseItemExporter.export_empty_fields"), [`encoding`](#scrapy.contrib.exporter.BaseItemExporter.encoding "scrapy.contrib.exporter.BaseItemExporter.encoding").

`export_item`(_item_)[¶](#scrapy.contrib.exporter.BaseItemExporter.export_item "永久链接至目标")

输出给定item. 此方法必须在子类中实现.

`serialize_field`(_field_, _name_, _value_)[¶](#scrapy.contrib.exporter.BaseItemExporter.serialize_field "永久链接至目标")

返回给定field的序列化值. 你可以覆盖此方法来控制序列化或输出指定的field.

默认情况下, 此方法寻找一个 serializer [在 item field 中声明](#topics-exporters-serializers) 并返回它的值. 如果没有发现 serializer, 则值不会改变，除非你使用 `unicode` 值并编码到 `str`， 编码可以在 [`encoding`](#scrapy.contrib.exporter.BaseItemExporter.encoding "scrapy.contrib.exporter.BaseItemExporter.encoding") 属性中声明.

<table><colgroup><col> <col></colgroup><tbody><tr><th>参数:</th><td><ul><li><strong>field</strong> (<a href="https://scrapy-chs.readthedocs.io/zh_CN/latest/topics/items.html#scrapy.item.Field" title="scrapy.item.Field"><code><span>Field</span></code></a> object) – the field being serialized</li><li><strong>name</strong> (<em>str</em>) – the name of the field being serialized</li><li><strong>value</strong> – the value being serialized</li></ul></td></tr></tbody></table>

`start_exporting`()[¶](#scrapy.contrib.exporter.BaseItemExporter.start_exporting "永久链接至目标")

表示exporting过程的开始. 一些exporters用于产生需要的头元素(例如 [`XmlItemExporter`](#scrapy.contrib.exporter.XmlItemExporter "scrapy.contrib.exporter.XmlItemExporter")). 在实现exporting item前必须调用此方法.

`finish_exporting`()[¶](#scrapy.contrib.exporter.BaseItemExporter.finish_exporting "永久链接至目标")

表示exporting过程的结束. 一些exporters用于产生需要的尾元素 (例如 [`XmlItemExporter`](#scrapy.contrib.exporter.XmlItemExporter "scrapy.contrib.exporter.XmlItemExporter")). 在完成exporting item后必须调用此方法.

`fields_to_export`[¶](#scrapy.contrib.exporter.BaseItemExporter.fields_to_export "永久链接至目标")

列出export什么fields值, None表示export所有fields. 默认值为None.

一些 exporters (例如 [`CsvItemExporter`](#scrapy.contrib.exporter.CsvItemExporter "scrapy.contrib.exporter.CsvItemExporter")) 按照定义在属性中fields的次序依次输出.

`export_empty_fields`[¶](#scrapy.contrib.exporter.BaseItemExporter.export_empty_fields "永久链接至目标")

是否在输出数据中包含为空的item fields. 默认值是 `False`. 一些 exporters (例如 [`CsvItemExporter`](#scrapy.contrib.exporter.CsvItemExporter "scrapy.contrib.exporter.CsvItemExporter")) 会忽略此属性并输出所有fields.

`encoding`[¶](#scrapy.contrib.exporter.BaseItemExporter.encoding "永久链接至目标")

Encoding 属性将用于编码 unicode 值. (仅用于序列化字符串).其他值类型将不变的传递到指定的序列化库.

### XmlItemExporter[¶](#xmlitemexporter "永久链接至标题")

_class_ `scrapy.contrib.exporter.``XmlItemExporter`(_file_, _item\_element='item'_, _root\_element='items'_, _\*\*kwargs_)[¶](#scrapy.contrib.exporter.XmlItemExporter "永久链接至目标")

以XML格式 exports Items 到指定的文件类.

<table><colgroup><col> <col></colgroup><tbody><tr><th>参数:</th><td><ul><li><strong>file</strong> – 文件类.</li><li><strong>root_element</strong> (<em>str</em>) – XML 根元素名.</li><li><strong>item_element</strong> (<em>str</em>) – XML item 的元素名.</li></ul></td></tr></tbody></table>

一个典型的 exporter 实例:

<?xml version="1.0" encoding="utf-8"?>
<items>
  <item>
    <name>Color TV</name>
    <price>1200</price>
 </item>
  <item>
    <name>DVD player</name>
    <price>200</price>
 </item>
</items>

除了覆盖 `serialize_field()` 方法, 多个值的 fields 会转化每个值到 `<value>` 元素.

例如, item:

Item(name=\['John', 'Doe'\], age='23')

将被转化为:

<?xml version="1.0" encoding="utf-8"?>
<items>
  <item>
    <name>
      <value>John</value>
      <value>Doe</value>
    </name>
    <age>23</age>
  </item>
</items>
