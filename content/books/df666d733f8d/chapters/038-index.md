# おすすめプラグイン

- [NERDTree](https://raw.githubusercontent.com/dofy/learn-vim/HEAD/ja/plugins/nerdtree.md)

  NERDTree は Vim のファイル閲覧プラグインです。コマンドでディレクトリツリーを
  開閉し、ファイルを閲覧・表示できます。

- [EasyAlign](https://raw.githubusercontent.com/dofy/learn-vim/HEAD/ja/plugins/easyalign.md)

  EasyAlign は文字位置を揃えるプラグインです。整った配置を好む人の強い味方です。

- [Airline とテーマ](https://raw.githubusercontent.com/dofy/learn-vim/HEAD/ja/plugins/airline.md)

  Airline は Vim に見やすいステータスバーを表示します。美しい配色と組み合わせると
  作業がより楽しくなります。

- [surround.vim](https://raw.githubusercontent.com/dofy/learn-vim/HEAD/ja/plugins/surround.md)

  `引用符`、`括弧`、`XML タグ`を対にして追加、置換、削除します。
