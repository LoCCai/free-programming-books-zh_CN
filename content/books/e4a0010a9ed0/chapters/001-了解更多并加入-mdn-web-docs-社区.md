自 2020 年 12 月 14 日起，MDN 一直运行在一个[在 GitHub 上进行维护](https://developer.mozilla.org/zh-CN/docs/MDN/Community/Our_repositories)的平台上。这为 MDN 带来了许多积极影响，但我们需要彻底改变我们处理本地化内容的方式。这是因为在我们的非英语本地化语言中，有很多内容未经维护且已经过时，我们希望将来能更好地管理这些内容。

**除了**以下语言，其他所有的本地化内容都已经归档，这意味着它们在 GitHub 上是只读的，不能在 MDN 上查看。活跃的本地语言有专门的团队负责维护。

## [如何贡献](#如何贡献)

如果你想为现有的某个活跃本地化语言做出贡献，请访问 [mdn/translated-content GitHub 仓库](https://github.com/mdn/translated-content "外部链接（在新标签页中打开）")。该仓库包含所有本地化文档以及议题跟踪。我们建议先阅读[翻译指南](https://github.com/mdn/translated-content/tree/main/docs "外部链接（在新标签页中打开）")。

如果你需要帮助或有任何疑问，请随时与下列活跃成员或社区取得联系，或[联系我们](https://developer.mozilla.org/zh-CN/docs/MDN/Community/Communication_channels)。
