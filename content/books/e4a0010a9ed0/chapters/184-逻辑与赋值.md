## 逻辑与赋值（&&=）

基线

广泛可用

自 2020年9月 起，此特性已在主流浏览器中得到支持，可在大多数设备和浏览器版本中正常使用。

-   [查看完整兼容性](#浏览器兼容性)
-   [了解更多](https://developer.mozilla.org/zh-CN/docs/Glossary/Baseline/Compatibility)

**逻辑与赋值**（`x &&= y`）运算仅在 `x` 为[真](https://developer.mozilla.org/zh-CN/docs/Glossary/Truthy)值时为其赋值。

## [尝试一下](#尝试一下)

```
let a = 1;
let b = 0;

a &&= 2;
console.log(a);
// Expected output: 2

b &&= 2;
console.log(b);
// Expected output: 0
```

## [语法](#语法)

js

```
expr1 &&= expr2
```

## [描述](#描述)

逻辑与的[_短路运算_](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Operator_precedence#%E7%9F%AD%E8%B7%AF%E8%BF%90%E7%AE%97)意味着 `x &&= y` 与下式等价：

js

```
x && (x = y);
```

如果左操作数不为真值，则由于[逻辑与](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Logical_AND)运算符的短路运算，不进行赋值操作。例如，由于 `x` 为 `const`（常量），以下式子不会抛出错误：

js

```
const x = 0;
x &&= 2;
```

也不会触发 setter 函数：

js

```
const x = {
  get value() {
    return 0;
  },
  set value(v) {
    console.log("调用了 setter");
  },
};
x.value &&= 2;
```

实际上，如果 `x` 不为真值，则根本不会对 `y` 求值。

js

```
const x = 0;
x &&= console.log("y 进行了求值");
// 什么都不会输出
```

## [示例](#示例)

### [使用逻辑与赋值](#使用逻辑与赋值)

js

```
let x = 0;
let y = 1;

x &&= 0; // 0
x &&= 1; // 0
y &&= 1; // 1
y &&= 0; // 0
```
