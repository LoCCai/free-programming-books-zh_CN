## 乘法（\*）

基线

广泛可用

自 2015年7月 起，此特性已在主流浏览器中得到支持，可在大多数设备和浏览器版本中正常使用。

-   [查看完整兼容性](#浏览器兼容性)
-   [了解更多](https://developer.mozilla.org/zh-CN/docs/Glossary/Baseline/Compatibility)

**乘法**（**`*`**）运算符计算操作数的乘积。

## [尝试一下](#尝试一下)

```
console.log(3 * 4);
// Expected output: 12

console.log(-3 * 4);
// Expected output: -12

console.log("3" * 2);
// Expected output: 6

console.log("foo" * 2);
// Expected output: NaN
```

## [语法](#语法)

js

```
x * y
```

## [示例](#示例)

### [数值乘法](#数值乘法)

js

```
2 * 2; // 4
-2 * 2; // -4
```

### [与 Infinity 相乘](#与_infinity_相乘)

js

```
Infinity * 0; // NaN
Infinity * Infinity; // Infinity
```

### [非数值乘法](#非数值乘法)

js

```
"foo" * 2; // NaN
```
