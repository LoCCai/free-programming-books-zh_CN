## 与 Java 语言比较

## Kotlin 解决了一些 Java 中的问题

Kotlin 通过以下措施修复了 Java 中一系列长期困扰我们的问题：

-   空引用由[类型系统控制](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/null-safety.html)。
-   [无原始类型](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/java-interop.html)
-   Kotlin 中数组是[不型变的](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/basic-types.html#%E6%95%B0%E7%BB%84)
-   相对于 Java 的 SAM-转换，Kotlin 有更合适的[函数类型](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/lambdas.html#%E5%87%BD%E6%95%B0%E7%B1%BB%E5%9E%8B)
-   没有通配符的[使用处型变](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/generics.html#%E4%BD%BF%E7%94%A8%E5%A4%84%E5%9E%8B%E5%8F%98%E7%B1%BB%E5%9E%8B%E6%8A%95%E5%BD%B1)
-   Kotlin 没有受检[异常](https://hltj.gitbooks.io/kotlin-reference-chinese/content/txt/exceptions.html)
