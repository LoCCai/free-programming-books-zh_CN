## 代码引用[¶](#id15 "Permalink to this headline")

正文内置::

@route('%s/'%ini.urlprefix) def index():

> \_\_urlog("INFO","idx++") return template('index.tpl',urlprefix=ini.urlprefix)

外部包含:

@route('%s/'%ini.urlprefix)
def index():
    \_\_urlog("INFO","idx++")
    return template('index.tpl',urlprefix\=ini.urlprefix)

## 表格线性声明[¶](#id16 "Permalink to this headline")

中文的非等宽性导致这种字符艺术式的图表很难作！ 所以,使用列表也可以方便的生成表格:

.. list-table:: 实例
   :widths: 15 10 30
   :header-rows: 1

   \* - Treat
     - Quantity
     - Description
   \* - Albatross
     - 2.99
     - On a stick!
   \* - Crunchy Frog
     - 1.49
     - If we took the bones out, it wouldn't be
       crunchy, now would it?
   \* - Gannet Ripple
     - 1.99
     - On a stick!

**效果**

实例[¶](#id22 "Permalink to this table")   
| Treat | Quantity | Description |
| --- | --- | --- |
| Albatross | 2.99 | On a stick! |
| Crunchy Frog | 1.49 | If we took the bones out, it wouldn't be crunchy, now would it? |
| Gannet Ripple | 1.99 | On a stick! |
