欢迎学习 C# 教程简介。 这些课程从可在 GitHub Codespaces 中运行的交互式代码开始。 在开始这些交互式课程之前，可以从 [C# for Beginners 视频系列](https://aka.ms/dotnet/beginnervideos/youtube/csharp) 中了解 C# 的基础知识。

小窍门

**编程新手？** 从教程 1（[Hello world](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/hello-world)）开始，按顺序完成每个课程。

**来自另一种语言？** 可以浏览教程 1-2，并从 [元组和类型](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/tuples-and-types) 开始，获取可能新的概念。

所有教程都使用基于文件的应用。 可以使用 [我们的 GitHub Codespace](https://github.com/dotnet/tutorial-codespace) 或安装 [.NET SDK](https://learn.microsoft.com/zh-cn/dotnet/core/install/)，并且已准备好开始。

第一课使用小代码片段来解释 C# 概念。 你将了解 C# 语法的基础知识，以及如何使用字符串、数字和布尔值等数据类型。 这一切都是交互式的，你将在几分钟内编写并运行代码。 这些第一课假定事先不知道编程或 C# 语言。 每个课程都基于前面的课程。 应按顺序执行这些作。 但是，如果你有一些编程体验，则可以跳过或浏览第一课，并从任何新概念开始。

若要使用 GitHub Codespaces，需要创建免费的 [GitHub](https://github.com) 帐户。

## 世界您好

在 [Hello world](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/hello-world) 教程中，将创建最基本的 C# 程序。 探索类型 `string` 及其文本处理方法。

## C# 中的数字

在 [C# 中的数字教程中](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/numbers-in-csharp) ，你将了解计算机如何存储数字以及如何使用不同的数字类型执行计算。 你了解舍入的基础知识，以及如何使用 C# 执行数学计算。

## 元组和类型

在 [元组和类型](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/tuples-and-types) 教程中，你将了解如何在 C# 中创建类型。 可以创建_元组_、_记录_、_结构和__类_类型。 这些不同类型的功能反映了其不同用途。

## 分支和循环

[分支和循环](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/branches-and-loops) 教程介绍了基于变量中存储的值选择不同代码执行路径的基础知识。 你将了解控制流的基础知识，这是程序如何做出决策并选择不同作的基础。

## 列表集合

[列表集合](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/list-collection)课程将介绍存储一系列数据的列表集合类型。 了解如何添加和删除项目、搜索项目以及对列表进行排序。 可以浏览不同类型的列表。

## 模式匹配

[模式匹配](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/pattern-matching)课程介绍了_模式匹配_。 通过模式匹配，可以将表达式与模式进行比较。 匹配的成功决定了要遵循的程序逻辑。 模式可以比较类型、类型的属性或列表的内容。 可以通过使用`and`、`or`和`not`逻辑组合多个模式。 模式提供了丰富的词汇来检查数据，并根据该检查在程序中做出决策。
